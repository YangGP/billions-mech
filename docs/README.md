## 设计基准与阅读顺序

[建筑目录 V2](building-roster-v2.md)保留 31 类建筑、参考作品对应、升级路线和六项终局工程候选；[资源与建筑 V1](resource-building-proposal-v1.md)保留经济方向及原始开局推导。两者是设计来源，V1 的建筑目录被 V2 替代，原始账面推导不等于当前运行结果。

当前规则查系统专稿，当前数值查数值表，完成度只查开发计划。设计候选与实际实现不一致时先记录差异，不能据旧草案回退代码。P0–P8 详细要求保留于一份[交接规格](ai-development-handoff.md)，不再并行维护第二套分批计划。

历史批次流水及过期交接总结已清理；独有的性能测量、算法接线、地图生成证据见[验证索引](../validation/README.md)。历史版本从 Git 查询，不能继承旧版本的人工验收为当前验收。
