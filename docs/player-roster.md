# 玩家兵种设计稿

2026-11-11。阵容结构已采纳并接入运行代码：**3 基础兵种 + 3 高级兵种**。当前运行单位为侦察兵、卫兵、榴弹兵、重装机甲、磁轨机甲、堡垒机甲 6 种。

资源设计命名：碳晶（原燃料）、超导矿（原稀有晶体）。运行 Resource ID 仍为 `fuel` / `crystals`，界面显示名已切换。

## 1. 阵容

| 层级 | 兵种 | 定位 | 工厂 |
| --- | --- | --- | --- |
| 基础 | 侦察兵 | 侦察/视野 | 组装厂 I |
| 基础 | 卫兵 | 线列/驻防 | 组装厂 I |
| 基础 | 榴弹兵 | 小范围爆破 | 组装厂 I |
| 高级 | 重装机甲 | 近战双目标肉盾 | 重装工厂 II |
| 高级 | 磁轨机甲 | 远程点名 | 高级重装工厂 III |
| 高级 | 堡垒机甲 | 双主武器：近距主炮/远距飞弹 | 高级重装工厂 III |

不再纳入本阵容：焚化者、束缚者。两者作为历史提案从 Git 查询，不作为当前设计目标。

## 2. 设计前提

- 不引入主动技能、姿态、额外指令；兵种差异来自面板与被动命中效果。
- 不新增工厂、研究项；沿用组装厂 → 重装工厂 → 高级重装工厂。
- 不做目标优先级 AI、手动切换双武器、护甲/伤害类型表、击退、治疗/维修、飞行、老兵等级；堡垒机甲的主炮/飞弹是自动二选一的双主武器，不是主动技能。
- 减伤与护甲走现有统一入口；榴弹兵只增加命中时的 `splash_radius`，不新增伤害类型。
- 玩家无友伤；榴弹兵爆炸默认不伤友军。
- 兵不能替代塔；基础兵对杂兵的每容量效率应低于塔与高级兵。
- 可读性：侦察=视野，卫兵=线列，榴弹=小范围爆炸，重装=近战双目标，磁轨=长射程单发，堡垒=主炮/飞弹双主武器自动二选一。

## 3. 基础兵种

### 3.1 侦察兵（侦察，组装厂 I）

| 项 | 值 |
| --- | --- |
| 配方 | 20 币 / 2 金属矿 |
| 工期 / 调度 | 12s / 1 |
| HP | 60 |
| 伤害 / 间隔 | 6 / 1.0s |
| 射程 / 索敌 | 4 / 6 |
| 移速 / 视野 | 3.0 / 9 |
| 被动 | — |

- **定位**：眼睛与早期补位，全阵容最高视野。
- **职责**：开局探图、给塔提供视野、清少量落单游荡敌。
- **反制风险**：打不死精英；长足者可以顺手清掉。
- **操作**：低，框选探路。

### 3.2 卫兵（线列，组装厂 I）

| 项 | 值 |
| --- | --- |
| 配方 | 20 币 / 2 金属矿 |
| 工期 / 调度 | 20s / 2 |
| HP | 100 |
| 伤害 / 间隔 | 10 / 0.8s |
| 射程 / 索敌 | 4 / 6 |
| 移速 / 视野 | 2.5 / 7 |
| 被动 | 可进驻碉堡 |

- **定位**：便宜、可进驻，填塔与塔之间的缝。
- **职责**：前中期填线；进驻碉堡后射程 +2/+3。
- **反制风险**：对高护甲/高 HP 精英输出不足；对臼炮几乎无解。
- **设计作用**：保证“空余容量买卫兵不亏”的通用性下限。

### 3.3 榴弹兵（小范围爆破，组装厂 I）

| 项 | 值 |
| --- | --- |
| 配方 | 60 币 / 6 金属矿 |
| 工期 / 调度 | 30s / 2 |
| HP | 130 |
| 伤害 / 间隔 | 18 / 1.6s，单目标 11.25 DPS |
| 爆炸半径 | 1.0 格 |
| 射程 / 索敌 | 4.5 / 6 |
| 移速 / 视野 | 2.1 / 7 |
| 被动 | 命中时对半径 1.0 内敌人造成小范围伤害；无友伤 |

- **定位**：基础兵里唯一的范围伤害，处理挤在破口、墙后、塔下的小簇。
- **与卫兵分工**：卫兵单体效率更高、可进驻；榴弹兵单目标弱，但命中 2–3 只时总输出更高。
- **与塔分工**：塔仍是清杂兵海主力；榴弹兵补塔的盲区、补破口。
- **反制风险**：单目标 11.25 DPS，对重装/臼炮很慢；敌人分散时溅射浪费；身板只比卫兵厚一点。
- **不做的**：不给持续燃烧、不给友伤、不给主动投掷技能。
- **为什么是基础兵**：前期就需要处理小簇和墙后目标；如果放到高级，会重演“没有范围兵就守不住破口”的问题。

## 4. 高级兵种

### 4.1 重装机甲（近战肉盾，重装工厂 II）

| 项 | 值 |
| --- | --- |
| 配方 | 160 币 / 6 金属矿 / 10 合金 |
| 工期 / 调度 | 60s / 4 |
| HP | 700 |
| 伤害 / 间隔 | 45 / 1.5s |
| 射程 / 索敌 | 1 / 6 |
| 移速 / 视野 | 1.8 / 7 |
| 被动 | 近战横扫：每次攻击最多命中 2 个近战范围内目标；主目标全额，副目标 60% |

- **定位**：幕二“墙外那一坨铁”，贴脸顶破口、护送榴弹兵、近身拆臼炮。
- **职责**：回收者 7s 内解决；拾荒者 1v1 能赢；被围时用双目标横扫清贴身杂兵。
- **反制风险**：必须贴到 1 格才能输出，远程敌人可以放风筝；移速 1.8，追长足者吃力。
- **设计作用**：最不容易用错的兵，高级线锚点。
- **双目标口径**：不是全额打两个，副目标只吃 60%，避免近战一进场就把杂兵海清空。

### 4.2 磁轨机甲（远程点名，高级重装工厂 III）

| 项 | 值 |
| --- | --- |
| 配方 | 320 币 / 8 金属矿 / 18 合金 / 12 超导矿 |
| 工期 / 调度 | 90s / 6 |
| HP | 600 |
| 伤害 / 间隔 | 180 / 3.0s |
| 射程 / 索敌 | 9 / 11 |
| 移速 / 视野 | 1.8 / 9 |
| 被动 | — |

- **定位**：用射程换安全的手术刀。
- **职责**：越人墙点名偏转者；在臼炮 8 格射程外反炮；在静默者 6 格干扰外点杀。
- **自罚**：180 伤害对 30 HP 杂兵严重过量，对群效率极低。
- **反制风险**：3s 一发，被 3 只以上长足者贴身就来不及；12 超导矿 + 6 调度，数量天然个位数。
- **可选调整**：若试玩发现磁轨通解，先降为 150 / 3.5s，再考虑削 HP。

### 4.3 堡垒机甲（主炮/飞弹双主武器，高级重装工厂 III）

| 项 | 值 |
| --- | --- |
| 配方 | 500 币 / 16 金属矿 / 30 合金 / 20 超导矿 |
| 工期 / 调度 | 120s / 8 |
| HP | 1800 |
| 主炮伤害 / 间隔 | 80 / 1.0s，爆炸半径 1.25，射程 3 |
| 飞弹伤害 / 间隔 | 90 / 8s，射程 10，单目标 |
| 目标选择 | 最近敌人距离 ≤3 用主炮；>3 且 ≤10 用飞弹 |
| 移速 / 视野 | 1.9 / 8 |
| 武器规则 | 主炮与飞弹都是主武器，同一时间只能使用一个，不齐射 |

- **状态**：已采纳设计，待接入运行代码。
- **定位**：“一个东西顶一段防线”，近距离用主炮清小簇，远距离用飞弹点远程/攻城单位。
- **职责**：顶破口、给磁轨与榴弹兵当掩体、单守次要方向；飞弹处理臼炮/偏转者等远程敌人。
- **代价**：8 格容量约等于幕三军队的 1/5；120s 工期 + 20 超导矿。
- **刻意不给**：减伤、主动切换武器、手动指定飞弹目标；武器切换是自动距离规则。
- **反制风险**：被 3 类近战精英同时围仍会死；飞弹 8s 一发，不能替代磁轨的持续点名；主炮射程只有 3，敌人退到 4 格后主炮完全打不到。
- **武器切换**：敌人距离进入 3 格立即切主炮；离开 3 格后切飞弹。建议实现时加 0.5 格滞回，避免在 3 格边界反复切换。
- **飞弹边界**：飞弹可打任何 >3 格的目标，不再限定“远程单位”；但 8s 间隔决定它只能补刀/反炮，不能当持续输出。

## 5. 对策矩阵

◎ 主解　○ 有效　△ 勉强　× 无效　▼ 用错会帮敌人

| 兵种 | 建造者海 | 回收者 | 拾荒者 | 偏转者 | 长足者 | 臼炮 | 静默者 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 侦察兵 | △ | × | × | × | △ | × | △ |
| 卫兵 | ○ | △ | △ | △ | △ | × | ○ |
| 榴弹兵 | ○ | △ | △ | △ | △ | △ | △ |
| 重装机甲 | ◎ | ◎ | ○ | △ | ○ | ○ | ○ |
| 磁轨机甲 | × | ◎ | ◎ | ◎ | ○ | ◎ | ◎ |
| 堡垒机甲 | ○ | ◎ | ◎ | ◎ | ◎ | ◎ | ○ |

读表要点：

- 磁轨是精英主解，但代价是对群效率极低、12 超导矿和 6 调度。
- 杂兵海主解是塔 + 榴弹兵；榴弹兵只清小簇，不替代塔。
- 重装机甲改近战后，贴脸清杂兵更强，但会被远程敌人放风筝。
- 堡垒主炮清 3 格内小簇，飞弹打 3 格外的目标；它是臼炮/偏转者的后期答案之一，但不替代磁轨的持续点名。
- 长足者没有减速兵后，解法变成“堡垒顶住 + 磁轨/卫兵集火”，不再有单一控制兵。
- 静默者仍靠“每个方向至少两个火力源”的编成纪律，而不是某个兵种。

## 8. 实现边界

**需要新增**

- 单位面杀伤：`unit_definition.gd` 增加 `splash_radius`；`unit_system.gd` 命中时复用塔与臼炮已有的溅射循环。
- 榴弹兵半径 1.0；堡垒机甲主炮半径 1.25；默认无友伤。
- 重装机甲近战双目标：增加副目标数 1、副目标伤害比例 0.6；只在攻击距离 1 内生效。
- 堡垒机甲双主武器：增加主炮/飞弹两组主武器字段和自动选择器；最近敌人 ≤3 用主炮，>3 用飞弹；同一 tick 只允许一个武器开火，不齐射。
- 堡垒机甲、榴弹兵的单位定义、成本、生产建筑与模型接线。

**明确不做**

- 主动技能、姿态、目标优先级 AI。
- 手动切换双武器、护甲/伤害类型表、击退。
- 治疗/维修单位、飞行、老兵等级。
- 友伤开关。

## 9. 校准目标与待定

| 指标 | 目标 |
| --- | --- |
| 基础兵对杂兵 TTK | 卫兵 2.4s / 榴弹兵 2.7s（每只 30 HP，溅射另算） |
| 高级兵对精英 | 磁轨 ≤ 8s；堡垒 ≤ 15s |
| 基础兵每容量效率 | 不高于同阶段塔的等效输出 |
| 高级兵容量占比 | 幕三不超过 50% |

待定：

1. 榴弹兵基础数值是否足够“低单体、强小群”。
2. 重装机甲近战双目标的副目标 60% 是否过高；若过强先降副目标到 50%。
3. 堡垒机甲飞弹 90/8s 是否过强；若过强先降伤害到 70，不削主炮。
4. 堡垒机甲的 8 调度是否过高，是否需要降到 7。
5. 磁轨是否降到 150 / 3.5s。
6. 主炮/飞弹在 3 格边界的切换是否需要 0.5 格滞回；建议需要，避免反复切换。
7. 后续是否还需要第 7 个兵；本稿认为不需要，先验证六兵种是否覆盖全部威胁。
