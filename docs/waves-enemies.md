# 敌种与波次（威胁设计）

> 本稿不含具体数值，可调参数以参数槽占位（数值见 values.md）。

## 1. 总览：威胁双通道

- **游荡敌（连续压力）**：全图常驻的散兵，被噪声吸引缓慢聚拢——首波前唯一的威胁来源，探图接敌、战斗与发展的代价。
- **波次（离散压力）**：按档级来袭的大股机潮——从首波起贯穿全场的节奏骨架。
- 结构：**前期靠游荡敌连续加压，中后期靠波次离散抬升**；两者用同一批敌种、同一套战斗规则（守"同一个世界"）。

## 2. 静默期与首波触发

- **静默期**：开局起约 10min（参数槽）内不来波次；此间压力 = 游荡敌 + 噪声聚拢。
- **首波触发 = 时间或发展度，先到先来**：
  - **时间线**：静默期满（10min，参数槽）。
  - **发展度线**：算力节点数达到阈值（参数槽）。不可被稀释（建节点本身就在涨它），与一幕电力天花板联动：节点触顶 ≈ 发展撞墙，首波恰好来考验。
- 触发达成瞬间发出首波预告（见 §6），预告后短延迟（参数槽）来袭。

## 3. 波次档级（三级 × 动态强度）

- **三个等级**：初级 / 中级 / 高级——**等级内不做固定分档，强度动态连续调整**。
- **等级 ↔ 幕映射**：初级 = 幕一、中级 = 幕二、高级 = 幕三。主脑升级后波次等级整体上移一级；幕内强度持续爬升（数量缓涨）——对应基础文档 §7"升级后威胁基线再抬一档"。
- **等级内动态强度（威胁预算模型）**：每波生成按"威胁预算"（参数曲线，随幕内波序递增）从敌种池取样构成；预算花在数量与构成配比上，实现上即 WaveDirector 按预算填充 WaveDef 构成。各敌种威胁单价与混合比例的具体数值归数值稿。
- **无波数上限**：每幕内波次无限循环、预算续涨——拖延升级与拖延终波的代价由此天然覆盖，无需额外机制。
- **节奏**：首波后固定间隔来袭（10min/波，参数槽；幕一名义 4 波，拖延续涨，波内按 TAB 式从边缘涌入）；终波为高级等级的专属编排（玩家召唤后来袭，守住即胜——game-design-concept.md §3）。

## 4. 游荡敌与噪声系统

- **生态**：开局按密度参数（参数槽）散布全图可行走区域；被清剿后从地图边缘缓慢回填（回填率参数槽）——世界是活的。强度跟随当前幕等级，个体明显弱于波次敌。
- **基地禁刷**：初始散布与边缘回填均排除地图配置的主脑占地安全半径；数值见 values.md §15。游荡敌后续仍可正常行走或闻声趋近。
- **噪声源分级**（吸引半径与强度均为参数槽）：
  - **战斗**（强）：枪声炮响，大半径吸引。
  - **施工**（中）：建造与拆除的动静。
  - **运转**（弱、持续）：生产与建筑日常噪音，低半径、长时效。
  - **移动**（弱、持续）：玩家单位行军噪音，低半径、脉冲持续——扩张本身即暴露（2026-11-06 经 TAB 对照引入）。
- **聚拢行为**：游荡敌闻声**缓慢聚拢**（移动趋近，非瞬移、非刷新增援）——形成"越打越围"的压力感；离开噪声源后滞留游荡。聚拢的具体移动走流场/寻路分轨（architecture.md §5），不新增移动系统。
- **设计后果**：初期"探图接敌"有真实代价——打一场小的，可能引来一场大的；发展越猛、噪声越多、游荡敌围得越紧。失败可追溯："是我吵得太狠"，不是被暗算。

## 5. 出身与路径

- 沿用 map-terrain.md §2：波次从**边缘可行通段**出生；**多数波次走主口**（2–4 个地形隘口），**少数波与终波可从开放段**来袭——"不能完全背对任何方向"。
- 游荡敌不走波次出生带——它们本来就在图上（回填时从边缘入场）。

## 6. 强度预告（定性）

- 预告**只给定性描述**：如"侦测到小股机潮""大量敌人正在逼近""侦测到强敌信号"——不显示具体数量、不显示构成。
- 预告内容 = 等级的定性档（小股 / 常规 / 大量 / 强敌）+ 来袭方向；方向分两级（vision-fog.md §6）：**默认给粗方向**（地图外来向，哪条边），**雷达站升级为精确扇形 + 更早预告**。
- 呈现位置：HUD 顶部波次槽（operations.md §8）；首波触发即预告（§2）。

## 7. 首次精英波（幕一后半）

- 位置：初级等级的爬升后段（幕一后半），威胁预算中引入**首个精英（原型机）**。
- 设计意图（building-economy.md §9.8）：堵死三条路——塔打不动（血厚+庇护）、墙拦不住（跨墙）、放任则防线被拆（攻城伤害）——唯一解是调兵，逼玩家从"只靠炮塔"转向"调兵"。规格见 §8.2。

## 8. 敌种（当前三种）

> 原则：敌人的"底层逻辑"是文本设定（flavor），不是模拟系统——**敌人不自增殖**，数量与构成始终由 WaveDirector 按预算生成（§3）；**唯一例外是感疫转化（§8.1）**。文本负责"敌人为什么存在、为什么这样行动"，模拟只实现明确列出的机制。

### 建造者（基础杂兵）

- **文本设定**：游荡在地面上的量产机器人，残破但数量巨大；底层逻辑是采集-建造——残骸与零件在它们手中变成新的机体与工事。
- **定位**：波次与游荡敌的数量主体。
- **机制**：无特殊机制。撞墙打墙、就近索敌、直扑主脑（通用目标策略）。
- **惩罚 / 解法**：无视野蛮数量 / 炮塔面杀伤与防线纵深。
- **参数意图**：HP 低、单价低——威胁预算里的"便宜大碗"，预算主要花在它的数量上。

### 回收者（破坏-回收）

- **文本设定**：机体厚实，与建造者群同行；底层逻辑是破坏-回收——拆解一切，把废墟变成原料。
- **定位**：开路先锋 + 经济惩罚。
- **机制**：优先攻击建筑（墙 > 炮塔 > 其他）；每摧毁玩家资产，触发感疫转化（§8.1）——它拆解的废墟当场变成新敌人。
- **惩罚 / 解法**：防线被啃、放任拆解 = 敌群当场滚大 / 集火拦截、不留残值。
- **参数意图**：HP 高、攻速低、单价中——威胁预算中的"质量件"。

### 8.2 原型机（首个精英，幕一后半登场）

- **文本设定**：失控前的原型工程机体，比量产机完整得多；它走到哪，机潮就受到它的电磁场庇护。
- **定位**：精英攻城锤——波次里的"必须处理项"，逼玩家从"只靠炮塔"转向"调兵"。
- **机制两件套**：
  - **电磁庇护**：周围机潮受其庇护，减伤（比例=参数槽，半径=参数槽）；杀死它 = 解除庇护——集火它是显式最优解。
  - **跨墙**：直接翻越装甲墙（翻越动作时间=参数槽，期间暴露可打）；不翻建筑（被建筑挡路则攻击开路，直扑主脑）；不爬障碍地形。
- **数值身份**：**血厚**（吸收炮塔火力的能力内建在身板）+ **高建筑伤害**（攻城定位：对建筑输出显著高于对单位——放任它，墙与建筑会被快速拆除）。
- **惩罚 / 解法**：塔打不动（血厚）、墙拦不住（跨墙）、放任则防线被拆 → 部队必须上 / 集火原型机、留小队守缺口、电磁陷阱迟滞（陷阱对它有效）。
- **参数意图**：HP 高（"基础单位小队集火可杀"量级）、移速慢、单价高、对建筑伤害高/对单位伤害低（比例=参数槽）；幕一后半每波 1–2 个；三幕反精英单位（重装工厂）是后期正式答案。

### 8.1 感疫转化（通用规则）

> 玩家资产被敌方摧毁 → **当场从废墟中生成机器敌人**。这是"敌人不自增殖"原则的唯一例外。

- **适用范围**：**仅占算力容量的资产**——功能建筑 + 全部单位，凡被敌方摧毁即触发。
- **装甲墙豁免**：墙（及一切占容为 0 的纯防线件）不感疫——退守弃墙不被二次惩罚，防线本身是安全的；感疫压力集中在经济与军力资产上。
- **不触发**：玩家主动拆除与清除基座（受控行为不产敌，否则惩罚"敢重构"，与 building-economy.md §9.6 冲突）；取消施工（无实体损失）。被毁转基座时感疫照常在被毁瞬间触发（building-economy.md §4.1）；基座本身不可被攻击、不再产敌。
- **产量规则**：按被毁资产造价定比换算（换算比参数槽），不设产量上限。
- **产出构成随威胁进化**：按**当前波次等级**（幕一建造者 / 幕二混入回收者 / 幕三可出原型机）+ **当前游荡敌存量 / 幕内波序**取样——威胁越深，废墟里爬出来的越强越多。
- **不限制生成，靠运行时治理**：规模用算法消化——**分区休眠**（无威胁区块的敌人进入低频模拟）、**迷雾外降档**（玩家视野外的敌人降低更新频率）、**降速阀**（负载超阈值时整体放慢 tick 节拍，宁可慢不许卡）。治理策略详见 architecture.md §9。
- **感疫噪声脉冲**：感疫爆发产生一次"战斗级"噪声，吸引周边游荡敌聚拢——防线失守会**连锁**：塌一段 → 爬出敌人 → 吸引来更多 → 下一段更难守。崩溃过程可读、可追溯，玩家看得到雪崩怎么滚起来，而不是突然被淹。
- **设计后果**：
  - 损失是即时且可见的惩罚：丢掉的资产当场变成敌情；
  - 废弃防线不随时间贬值：越后期丢东西越疼，"逐层退守"的每一步退让都要算清感疫账；
  - 失败可追溯：玩家亲眼看着自己的建筑变成敌人。

### 与噪声系统的联动

- 建造者群的日常移动即"运转级"弱噪声源（它们本来就在图上游荡）；战斗与施工噪声吸引它们的聚拢行为不变（§4）。

## 9. 非目标

- 不做剧情 Boss（原型机/重装机是精英，不是脚本演出单位）。
- 不做波次之间的"安全期奖励"（守住就是奖励：时间与噪声暴露减少是自然收益，不做显式奖励）。
- 不做游荡敌的巢穴/生态模拟（密度与回填是参数，不是拟真系统）。
- **不做敌方自主经济**（敌人不采集、不自增殖；"采集-建造/破坏-回收"是文本设定，非模拟系统）。
- 敌种行为树、接敌判定半径数值、雷达预警强度——留后续轮，本文只留接口。
