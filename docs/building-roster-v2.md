> 设计基准：保留31类建筑的职能、参考对应与六项未实施终局工程。当前运行数值以[数值表](values.md)及 Resource 为准；接入/未开发/未验收状态统一见[开发计划](development-plan.md)。下列设计费用与原始推导不冒充常速平衡或现行玩法验收。


2026-11-08原始目录。按参考作品的建筑分工设计；31类常规内容已经接入，新增规则和价格仍须试玩。六项终局工程只作候选，完成度不在本稿维护。

本页接管[资源与建筑 V1](resource-building-proposal-v1.md)的建筑目录、建筑升级和前置关系；资源产线、节点总量/系统预留、供电与冷却短缺规则仍以该稿为准。已加入风能/太阳能双路无燃料电源，并移除基础组装厂和卫兵的合金门槛；V1前10分钟核算同步改为无燃料开局。

## 1. 继承的经济规则

- 算力节点承担住宅的经济位置：同时产币与提供容量。I/II/III总量4/8/12，系统自用1/2/3，净可调度3/6/9；耗电2/4/7，冷却占用2/4/6。
- 冷却承担食物式的供给约束；主脑提供4启动冷却，冷却塔供给全基地共享。节点以外的单位/建筑不再直接扣冷却；单位通过调度容量间接受约束。
- 热能冶炼站把燃料发电与合金加工合并：基础站每15s消耗2燃料，周期内供电30；有1金属矿就同时投入、周期结束产1合金。缺金属矿仍发电，缺燃料则停炉。
- 风能站、太阳能站从开局开放，只花币和金属矿，不耗燃料、冷却或调度容量；基础经济、组装和防线可以完全依靠无燃料电力发展。燃料主要决定合金产能与后续工业扩张，不再是前期供电的必经入口。
- 风能/太阳能参照猎人小屋、渔场的环境采集方式：小占地建筑利用周围地格，选址决定产量，同类采集区域排他；12电/14电是开局参考产量，不再是任意位置的固定产值。冷却仍承担食物式供给约束，二者借鉴的是不同职能。
- 金属矿、合金、末期稀有晶体是三种建设材料；算力币为货币，燃料矿为运营库存。冷却、电力、调度均为额度，不是库存。
- 稀有晶体只在第三阶段采掘、使用；主脑升III、科技中心升II和第一座晶体采掘站都不吃晶体。
- 保留有限矿藏、共享库存、无库存上限。没有管道、运输单位、冷却液、水资源、食物资源或常驻币维护费。
- 数值电力/冷却不足只限制新增相关订单，已有覆盖内设施保持既有服务；空间覆盖断开仍停运。普通掉血不更新供给、加成范围或导航场。
- 主脑是唯一失败锚点；调度中心只管理同一批资源与单位，不产生资源或战斗加成。

## 3. 常规目录：31类基础建筑

基础建筑按独立建造类型计数，升级形态不重复计数，预置主脑计入其中。另有6项终局工程候选。费用统一为 **币/金属矿/合金/晶体**；调度、电力为下单预留的额度。只有节点直接占冷却。**主脑各级5×5，风能站各级1×1，太阳能站各级2×2**；所有升级保持原占地，闸门固定1×2。

阶段I＝开局至第一次主脑升级前；II＝主脑II；III＝主脑III。组装厂与减速栅从I阶段开放，不要求先炼合金；科技中心I仍以曾经产出第一份合金为前置，不检查当前合金余额是否仍大于零，不另收隐藏研究费。

### 3.4 风能与太阳能：环境采集区

参考开发者介绍的[猎人小屋/渔场按周围环境决定产量、放置前预览的思路](https://store.steampowered.com/news/posts/?appids=644930&enddate=1511343053)。以下地形权重、范围、上限和重叠处理均为本作提案，不是原作数值。

| 项目 | 风能站 | 太阳能站 |
|---|---|---|
| 本体占地 | 1×1 | 2×2 |
| 采集区 | 占地向四周各扩3格，即7×7区域 | 占地向四周各扩3格，即8×8区域 |
| 地格评分 | 已探索的崎岖地或风口格每格1分，普通开阔地每格0.5分；同格取最高，不叠加 | 已探索的开阔地每格1分 |
| 无效地格 | 本体占地、岩体/峡谷等障碍地、水面、地图外与未探索格均为0 | 本体占地、崎岖地、障碍地、水面、地图外与未探索格均为0 |
| 基础供电 | `min(18, floor(评分/2))`；评分24时12电 | `min(20, floor(评分/2))`；评分28时14电 |
| 强化供电 | 同一选址基础值×2，上限36 | 同一选址基础值×2，上限40 |

- 风口是可选静态环境标记，可用于迎风高地或岸边陆地；只影响产量评分，不改变可建造/通行规则。风能可在普通开阔地发展，不要求地图必须有水或风口。
- 普通建筑、矿点与移动单位不改环境潜力评分；本体占地始终不计分。第一版不做建筑投影遮光、风向模拟或动态建筑遮风，避免普通建造/受击使供电频繁变化。
- **同类采集区不得重叠**，包含基础/强化形态；采集区按完整方形范围校验，不能通过重叠部分暂时无产量或尚未探索来绕过。风能与太阳能属于不同类型，可以重叠使用环境，但本体仍不能相互占格。
- 在建即预留采集区；停用、断网和保留基座时仍保留区域，取消施工、拆除或清基座才释放，重建不重复申请。升级不扩区、不改类型。
- 采集区是环境利用规则，不是实体占地，不阻挡单位与其他建筑，不要求每个贡献格都在供电覆盖内；只有本体需满足既有供电覆盖与可建造校验。
- 放置时显示采集区、有效格/权重与预计电量；同类冲突格标红，0产量位置禁止下单。未知格不计分、不泄露地形；新地格探明时仅重算其影响的附近电源。
- 供给仅随完工、升级、探索记忆新增、地形/环境数据变化或运营状态改变更新；移动和普通受伤不触发供给或导航重算。区域预约只防同类重复利用，不增加任何全图行军场计算。
- 制图须在主脑/首段中继可达范围内，提供至少一个已探索风能评分24以上的位置及一个已探索太阳能评分28以上的位置，并留出5×5主脑和基础建筑用地。它们可以跨类型重叠采集区，维持V1无燃料开局的12＋14电核算前提。新128×128开发图的地形/选址数据已检查，环境发电系统运行与完整开局验收仍待P2；见[地图检查](../validation/development-map-128/README.md)。

## 5. 阶段与解锁关系

| 进度 | 需要什么 | 开放内容 |
|---|---|---|
| 开局 | 主脑I | 基础节点、金属/燃料采集、热能冶炼、风能、太阳能、中继、两种基础冷却、墙门、碉堡、哨戒炮塔、瞭望哨、组装厂、减速栅；基础兵和防线不要求先取得燃料或合金 |
| I后段 | 曾经产出第一份合金 | 科技中心I；准备升级阶段，不另收科研费 |
| 升主脑II | 科技中心I＋升级材料 | 进入第二阶段，可升级科技中心II |
| II技术开放 | 主脑II＋科技中心II | 中期升级、经济辅助三站、接驳站、重装工厂、雷达、速射机炮、电弧塔、两种一次性陷阱、维修站；II后段不另设隐藏门槛 |
| 升主脑III | 科技中心II＋升级材料 | 进入第三阶段；立即允许晶体采掘，不要求已有晶体 |
| III技术开放 | 主脑III＋科技中心III | 三级节点、深冷塔、深层晶体、歼灭炮塔、电磁塔、高级重装工厂、调度中心；终局工程候选也由此开放 |

这条链是：科技I → 主脑II → 科技II → 主脑III → 晶体采掘 → 科技III。不存在“科技III需要晶体、晶体又需要科技III”的闭环。水冷为临水替代选项；风能和太阳能可单独或混合使用，不要求两种都造，燃料线可在基础经济与防线建立后接入。

## 6. 辅助设施的共同规则

### 6.1 矿区、节点区与加成

- 资源调配、负载均衡、结算半径均为8格，以逻辑格中心的欧氏距离判定；目标建筑中心进入范围才生效，不检查地形LOS。辅助设施自身与目标都要处于主脑连通覆盖内。
- 同类效果取最强，不因多站覆盖叠乘；不同职责可共存。资源调配只加金属/燃料矿的采集率，不给冶炼厂、晶体站、货币或供给额度加成，实际采出仍扣矿藏储量。
- 负载均衡只把节点的基础冷却需求乘0.8，不改电量或系统预留；以0.1点精度记账，节点I/II/III需求变为1.6/3.2/4.8。建设/升级订单按当前覆盖计算预留，设施状态变化后统一重算受影响节点的整份运营/订单需求，不重复打折。
- 结算只提高节点实际运行产币率，不加主脑币、不增加容量、不退建筑造价。所有增益随辅助设施完工、升级、断网、停用、拆毁而更新；普通掉血不刷新。
- 失去负载均衡导致冷却赤字时，按V1的短缺规则限制新增节点，现有节点不自动停机。建造UI预览真实冷却占用与范围内节点，不要求玩家手算小数。
- 不新增交易、自动卖料、库存上限和相互运输；这三座辅助建筑分别解决矿区、冷却、货币的单一问题。

### 6.2 接驳站与军工分工

- 每180s生成一份合同，最多存一份，合同内容为一名当前阶段可用的卫兵或常规重装机甲；III阶段才可能提供磁轨机甲。初建也等待首个周期，使用存档种子决定合同，不因暂停/读档刷新。
- 支付对应单位正常材料费，币为正常价150%，无免费单位；下单即预留同样调度容量。不另占冷却，仍由节点支撑军队。
- 外援满足主脑/科技等级条件，可省去该型号的本地生产厂，但受180s一单限制；长期补兵仍由组装厂、重装工厂完成。
- 接受合同后60s在接驳站出口交付；无合法相邻格则等待，不能落在墙内或占用格。合同占一个交付槽，未交付前不生成下一份。
- 取消未交付合同全退并释放预留；玩家主动拆站也退，敌人摧毁则订单损失并释放预留，沿用现有军工订单的风险语义。

### 6.3 防线与维修

- 门、墙、碉堡、炮塔是硬占地；减速栅、陷阱、地雷是可通行设施，不通过通行成本冒充全局引路墙。
- 控制效果取最强，不叠乘减速。减速栅只在格上生效；电磁陷阱、电磁塔按持续时间生效。驻军不获得穿透地形的射线或免除容量占用。
- 维修站延续V1：修满总材料费用暂定新建配方25%，按修复量累计扣除；受击后暂停，维修站不会修复敌人或凭空重造被毁建筑。
- 陷阱触发、驻军攻击、建筑受伤都不刷新静态行军场；只有硬占地变化走既有局部占用/导航更新。资源/加成账只响应相关运营状态变化。

## 8. 相比V1的明确变化与实施次序

31类建筑原始任务要求见[交接规格](ai-development-handoff.md)，当前差异和执行顺序只查[开发计划](development-plan.md)。本节保留设计演进，不另维护进度。

- 常规目录从19扩到31类，新增水冷、风能、太阳能、三种经济辅助、接驳、碉堡、瞭望、机炮、减速栅、地雷共12类；其余变化为已有建筑的升级与职责细化。B31为新增太阳能站，保留原B01–B30编号。
- 按用户确认，主脑占地5×5，风能1×1、太阳能2×2，各自升级保持同尺寸。风能/太阳能随后改为环境采集产量，强化改为同址基础值×2；造价、冷却、容量与工期保留。实施时放置预览、占用格、拾取轮廓与导航占用需支持5×5，不能沿用旧版只到4×4的尺寸分档限制。
- 原V1独立末期“电磁塔”改为“中期电弧塔→末期电磁塔”，避免中期缺少范围清杂；仍用晶体解锁末期形态。雷达从I后段推至II，前期情报由便宜瞭望哨承担。
- 科技中心由单纯存在前置变成I/II/III升级前置；没有追加单项研究树费用。主脑升III仍不吃晶体，晶体采掘不等科技III。
- 基础组装厂移除4合金、卫兵移除1合金，基础组装与减速栅不再等待首次合金。V1改用风能＋太阳能的无燃料开局核算，不使用光环或水冷；该表仍只证明基础子集无战损时账面可行，不能证明31类建筑已经平衡。
- 第一批：节点账、电/冷却恢复路径、金属、风能/太阳能、墙门、基础组装，并接入燃料/热能冶炼供后续升级。第二批：主脑/科技升级、强化供给、重装与电弧塔。第三批：经济光环、碉堡、接驳及完整防线工具。第四批：末期晶体、调度；终局工程单独排期。
