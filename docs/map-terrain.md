# 地图与地形

对应0.5.90-dev。现有“四隘盆地”“西岸前哨”“双桥河谷”三张正方形展示地图，几何总面积保持各自原图128×128、64×64、96×80的面积，各级主脑占地5×5。新关卡基地靠地图边缘，旧前哨与旧训练场未恢复。地图材料与验证边界见[开发图记录](../validation/development-map-128/README.md)、[新关卡记录](../validation/tutorial-maps/README.md)。

## 1. 数据来源与空间

布局源为 `content/maps/development_basin_128.source.json`，由 `tools/compile_development_map.py` 编译原生 `.tres` 和验证 bundle。玩法配置 `content/development_128.tres` 引用编译结果；修改地图须同步源及生成结果，不只改预览。

新关卡源分别为`content/maps/tutorial_coast_64.source.json`、`content/maps/validation_river_96.source.json`。沿用同一编译器；`--settings-output`还会以现有开发配置为模板，生成相应MechFoundationSettings，覆盖源中`session`列出的出生点、说明与波次字段。没有新增运行时地图生成器或导航算法。

2026-11-12改为斜向四边形可玩边界，在64×48等距投影和对应Camera3D角度下显示为轴对齐正方形。按用户补充要求扩大底层网格，保证几何总面积与原图一致：

| 地图 | 原几何面积（平方格） | 扩大后网格包围盒 | 完整可玩格 |
| --- | --- | --- | --- |
| 四隘盆地 | 16384 | 184×184 | 16042 |
| 西岸前哨 | 4096 | 96×96 | 3927 |
| 双桥河谷 | 7680 | 127×127 | 7403 |

几何面积包含显示边缘的半格，完整可玩格数单独统计，不能混称相等。源中`original_dimensions`/`target_playable_area`保留原面积基准，`playable_polygon`保存等面积边界，`closed_edges`沿指定边封岩体。分数顶点通过现有SciPy/Qhull保留精度，编译报告校验面积；不缩放单位、建筑、供给或移动距离。

模拟、导航、波次出生与建筑占地使用同一个完整格掩码，四个格角均在边界内才可用；建筑任一占地格越界即拒绝且不扣款。地面渲染复用Geometry2D裁剪保留边缘半格，让外轮廓平直；这些半格仅为地面装饰，不能建造或通行。小地图使用同一轮廓，不恢复旧二维战场。

镜头沿屏幕横纵轴夹持于正方形范围；当某轴视野比地图宽时，该轴固定在地图中心。普通缩放仍50%–200%，Home按真实边界留边适配。F1将主脑带回可见战场，边缘基地不再强制居中，避免绕过新的镜头边界。

## 2. 出生与进攻

四向主隘口和开放边缘共同构成进攻空间；多数波次从主口带进入，侧翼和终波可使用其他可行边缘。敌军在同一世界实际行军，不因进攻意图瞬移至基地。

上述四向布局对应四隘盆地。等面积扩展后主脑为四隘盆地(89,89)、西岸前哨(14,41)、双桥河谷(113,69)。西岸前哨距显示左边约2.9逻辑格，三边封口，开放边缘到基地仍经过12格宽单隘口。双桥河谷距显示右边约3.4逻辑格，靠东南角，右/下边封闭；河流延伸至新边界，保留两处6格宽陆桥。河流仍为水域障碍，无新增桥梁建筑或传送逻辑。地形、矿点、参考位和开局单位同步平移，矿点数与储量不变。

地图安全半径按主脑占地距离计算，开局散布和边缘回填共用28格禁刷范围；它不等于供电范围。游荡敌后续行走/闻声仍可接近基地。散兵数量随可用区域变化，不固定沿用扩展前记录，正式节奏仍需试玩。

## 3. 地形与环境层

| 类型 | 通行/建造 | 视线与环境 |
| --- | --- | --- |
| 开阔 | 可通行、可建造 | 不挡 LOS；太阳能有效格 |
| 崎岖 | 可通行、移动有权重，可建造 | 不挡 LOS；风能高分格 |
| 障碍 | 不通行、不可建造 | 挡实时 LOS；探索半径仍揭示其后地形记忆 |
| 风口标记 | 不新增地形种类 | 与崎岖一样给风能高分，同格不重复加分 |
| 水域标记 | 仍为障碍，不入库存 | 为正交邻水的水冷选址提供条件 |

环境评分只读取已探索地形。风冷1×1、7×7采集区，太阳能2×2、8×8采集区；同类排他，跨类可重叠。固定分母、封顶及参考供给见[资源](resources.md#5-无碳晶环境电源)，不能把某一参考位的电量当作所有位置固定产量。

## 4. 矿点

四隘盆地有8处金属矿、6处碳晶、5处外围超导矿，西岸前哨为4/3/2处、双桥河谷为6/4/3处；初始储量均为720/480/180每点。矿点不挡移动；采集站本体绑定一个未耗竭锚格，普通建筑不能覆盖未耗竭矿点。深层提高采速，不增加总储量。

灰色已探索区可显示已知矿点，未知黑区不泄露位置。矿点储量是会话状态，拆建不刷新；重开恢复初始值。超导矿作为末期扩张目标，不用于主脑升 III 的先决费用。

## 5. 防线与退守要求

主口、崎岖迟滞、初始腹地及外层→内层→核心两跳退守空间是地图结构目标，不要求前期立刻建多层防线。出生点固定，玩家做的是覆盖内的布局与扩张决策。

全局行军场只读取地形，局部场读取当前阻挡和可攻击位；遇墙拆墙、未接敌优先进附近破口、已攻击其他墙的敌人继续攻击，建筑只作顺路目标。普通伤害不重新计算全图。实现证据已归档，需要时从 Git 历史查询。

## 6. 验证与范围

生成材料中保留34个路线锚点及当时的连通/预览记录，不把离线连通当作当前窄口、建造、供电或完整退守的人工验收。正常运行保持迷雾；地图预览/诊断不作为额外玩法地图。

本轮已接入三张可选地图，同一时间只运行一局；不做程序生成、地形改造、立体层、运输管道或动态天气。新关卡是教程/玩法验证场地和菜单目标说明，不含逐步锁定操作的教学脚本；教程难度与完整经济/防守流程仍需试玩。
