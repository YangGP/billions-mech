# 地图与地形

对应 0.5.89-dev。唯一玩法地图是“四隘盆地”128×128，主脑占地5×5，旧前哨与训练场已删除。地图生成材料及其验证边界见[开发图记录](../validation/development-map-128/README.md)。

## 1. 数据来源与空间

布局源为 `content/maps/development_basin_128.source.json`，由 `tools/compile_development_map.py` 编译原生 `.tres` 和验证 bundle。玩法配置 `content/development_128.tres` 引用编译结果；修改地图须同步源及生成结果，不只改预览。

完整矩形逻辑边界为16,384格，64×48等距投影后为菱形。地形、建筑占用、覆盖、环境和视野各自维护，不因画面缩放改变。运行环境场景和地图预览使用同一地形定义。

## 2. 出生与进攻

四向主隘口和开放边缘共同构成进攻空间；多数波次从主口带进入，侧翼和终波可使用其他可行边缘。敌军在同一世界实际行军，不因进攻意图瞬移至基地。

地图安全半径按主脑占地距离计算，开局散布和边缘回填共用28格禁刷范围；它不等于供电范围。游荡敌后续行走/闻声仍可接近基地。当前开局散布记录为94只，正式节奏仍需试玩。

## 3. 地形与环境层

| 类型 | 通行/建造 | 视线与环境 |
| --- | --- | --- |
| 开阔 | 可通行、可建造 | 不挡 LOS；太阳能有效格 |
| 崎岖 | 可通行、移动有权重，可建造 | 不挡 LOS；风能高分格 |
| 障碍 | 不通行、不可建造 | 挡实时 LOS；探索半径仍揭示其后地形记忆 |
| 风口标记 | 不新增地形种类 | 与崎岖一样给风能高分，同格不重复加分 |
| 水域标记 | 仍为障碍，不入库存 | 为正交邻水的水冷选址提供条件 |

环境评分只读取已探索地形。风冷1×1、7×7采集区，太阳能2×2、8×8采集区；同类排他，跨类可重叠。固定分母、封顶及参考供给见[资源](resources.md#5-无碳晶环境电源)，不能把某一参考位的电量当作所有位置固定产量。

## 4. 矿点

运行地图有8处金属矿、6处碳晶、5处外围超导矿，初始储量分别为720/480/180每点。矿点不挡移动；采集站本体绑定一个未耗竭锚格，普通建筑不能覆盖未耗竭矿点。深层提高采速，不增加总储量。

灰色已探索区可显示已知矿点，未知黑区不泄露位置。矿点储量是会话状态，拆建不刷新；重开恢复初始值。超导矿作为末期扩张目标，不用于主脑升 III 的先决费用。

## 5. 防线与退守要求

主口、崎岖迟滞、初始腹地及外层→内层→核心两跳退守空间是地图结构目标，不要求前期立刻建多层防线。出生点固定，玩家做的是覆盖内的布局与扩张决策。

全局行军场只读取地形，局部场读取当前阻挡和可攻击位；遇墙拆墙、未接敌优先进附近破口、已攻击其他墙的敌人继续攻击，建筑只作顺路目标。普通伤害不重新计算全图。实现证据已归档，需要时从 Git 历史查询。

## 6. 验证与范围

生成材料中保留34个路线锚点及当时的连通/预览记录，不把离线连通当作当前窄口、建造、供电或完整退守的人工验收。正常运行保持迷雾；地图预览/诊断不作为额外玩法地图。

本轮不做程序生成、多图并行、地形改造、立体层、运输管道或动态天气。未来图池和资源平衡另行验收。
