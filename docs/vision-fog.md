# 视野与迷雾（侦察系统）

> 本稿维护视野规则，运行半径以[当前数值](values.md)及Resource为准。双用途定位：玩法系统（探索、雷达预警、伏击）+性能系统（迷雾外降档的前提，architecture.md §9）。

## 1. 迷雾三态

| 态 | 表现 | 内容 |
|---|---|---|
| 未探索 | 黑 | 地形未知 |
| 已探索 | 灰（记忆态） | 地形与建筑布局已知；敌方实体不显示 |
| 可见 | 实时 | 显示区域内全部实时实体 |

- 灰区为"记忆"：显示最后探知的地形与静态建筑；敌方单位离开视野即消失。
- 探索是单向的：已探索不回退。

## 2. 视线规则

- **探图 = 探索源半径**，不受岩体/峡谷遮挡；范围内地形先进入已探索灰态，即使从未获得实时视线。
- **可见 = 视野半径 + 视线（LOS）**；被挡住的地形保持灰态，敌方实体仍不显示。
- 当前探索源与视野源相同，使用现有同一半径，分别维护探索记忆与实时可见；本轮不另调半径数值。
- **障碍地形（岩体/峡谷）挡视线**——其后形成侦察死角；崎岖地不挡。
- 建筑不挡视线（实现从简；侦察死角来自地形，不来自建筑）。

## 3. 玩家视野来源表

| 来源 | 视野 | 说明 |
|---|---|---|
| 主脑 | 12格 | 开局初始可见区，各级一致 |
| 单位 | 小（参数槽） | 行军即侦察 |
| 哨戒炮塔 | 中（参数槽） | 防区即视区 |
| 雷达站 | 大（参数槽）+ 预警职能 | 当前提供更早预告，精确扇形尚未接入 |
| 普通建筑（墙/节点/中继/能源/工业等） | 默认4格 | 完工且连通后提供局部实时视野；专业建筑保留更大的显式半径 |

## 4. 探索范围 = 供电覆盖 ∪ 探索源半径

- **供电覆盖内 = 已探索（灰态）**：中继推到哪，地图亮到哪——电网即文明边界，中继推进同时获得供电与探索双重意义。
- **可见（实时）需要视野源及LOS**：所有完工且连通建筑都有局部视野，但供电覆盖可大于其视野半径，岩体也可能遮挡，覆盖内仍可能存在灰区。
- **探索源半径内同样进入灰态**：主脑、单位、所有完工且连通建筑与验证实体均可探明范围内静态地形；实时可见再受LOS约束。施工、被毁基座和断覆盖建筑不提供视野；源移除不清除已探索记忆。
- 开局已知 = 主脑初始供电覆盖 ∪ 初始探索源范围；初始可见还需 LOS。源离开或被移除后，已探索范围保留。

## 5. 敌人感知（听 + 看）

- **远程 = 听（噪声）**：游荡敌被噪声吸引缓慢聚拢（waves-enemies.md §4），大半径、慢速、可滞留。
- **近程 = 看（视觉仇恨）**：敌人有**小视觉半径**（参数槽），受同样 LOS 规则约束；玩家资产进入其视觉半径 → 即时仇恨、接敌攻击。
- **接敌判定（Marching → Engaged 切换）由此定义**：进入敌人视觉半径、或被攻击、或攻击范围内存在玩家资产——三个条件之一即接敌（architecture.md §5 的接口落位）。
- 设计后果：障碍地形后的侦察死角对敌我双向生效——玩家可以借地形潜伏逼近，敌人也会从死角里撞出来。

## 6. 视野外事件与方向分级

- 视野外的事件（波次来袭、感疫脉冲）**必给警报 + 粗方向**：指明"地图外来向"（哪条边/方位，小地图边缘指示）——所有玩家默认可得，兑现"不被暗算"。
- **雷达站当前提供更早预告**；精确扇形/小地图标记属于后续呈现目标，不把它描述为已有功能。
- 配合强度预告的定性描述（waves-enemies.md §6）：无雷达 = "大量敌人，东北方向"；有雷达 = "大量敌人，扇形 + 提前量"。

## 7. 性能与实现挂钩

- **迷雾层 = 第五网格层**（地形/占用/供电覆盖/成本场之外）：每格三态，sim 侧维护，表现层渲染。
- LOS 检查用障碍地形层；视野源注册 + 脏标记重算，不逐帧全图。
- **迷雾外降档**（architecture.md §9）：不可见区域的敌人降低更新频率与寻路精度——本系统是其前提，两者同批实现。

## 8. 非目标

- 不做潜行/隐身数值系统（侦察死角来自地形 LOS，不是单位属性）。
- 不做敌方迷雾（敌人感知独立于玩家迷雾：听 + 小视觉）。
- 不做探索度奖励/收集（探索的收益就是信息与选址）。
- 不做可破坏的视野遮挡物（岩体即永久死角，不给"打掉掩体"的战术层）。

## 9. 当前接入（0.5.89）

三态迷雾、覆盖探索、地形遮挡与探索记忆已实现。2026-11-09按用户要求将普通建筑默认视野由0改为4格，继续复用原建筑视野源和LOS缓存；主脑、炮塔、瞭望、雷达的既有显式半径保持。源半径内先记录探索，再用LOS判定实时可见。正常配置无免费验证实体，诊断fixture可显式启用；驻军退出地面单位视野来源。移动源按格更新，静止源复用缓存；表现层仅在版本变化时上传迷雾纹理。重开清探索，覆盖丢失或源移除不抹去记忆；己方建筑信息仍由己方账本提供。

玩家快照过滤视野外敌人和未知矿点，悬停/放置预览隐藏未知地形，地标探索后才出现；直接攻击和自动索敌受实时视野限制，失去追击目标后搜索最后看见的位置。波次保留粗方向文字预告，感疫新增粗方向文字警报。

不可见且远离己方资产的敌人按四倍间隔执行感知/游荡决策，噪声寻路重试间隔放宽四倍；仍逐 tick 移动、碰撞与结算冷却/伤害。接近己方资产、受击或交战时保持正常战斗响应，重回实时视野立即恢复正常寻路节奏。这是首批决策降频，尚非分区休眠或千级性能验收。左下角小地图已接入（三态迷雾、敌我/矿点/主脑点阵、镜头视野框与左键跳镜头，见[小地图检查](../validation/minimap.md)）；瞭望/雷达视野与预告窗口已经接入，正式警报历史、小地图扇形和覆盖着色仍待后续开发。检查证据见[实施记录](../validation/m6-vision-fog.md)。
