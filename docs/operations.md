# 操作与交互（控制方案）

> 目标范式：**混合**——经典 RTS 单位操控 + TAB 式建造热键栏 + 完全暂停可操作。现行键位见根目录 [README](../README.md)，实现进度见 [开发计划](development-plan.md)，模块选型见 [复用调研](reuse-research.md)。

## 1. 设计原则

- **建造优先 = 建造操作零摩擦**：建造全程不离开主视角、不进二级菜单、暂停随时可用。
- **微操上限低**：单位侧只保留"移动、攻击移动、编队"三件套；无主动技能、无姿态切换。
- **每条禁令都有原因**：放不下去的格子直接说明为什么（对应 building-economy.md §3.2 校验顺序）。
- 同一套操作从第一幕用到第三幕；区域层（未来）只做"授权"，不新增指令类型。

## 2. 暂停（完全暂停可操作）

- 键位：空格切换。
- **暂停只冻结时间推进**——施工、产币、波次计时、战斗全部停止；建造/生产等命令即时校验、付款并预留，单位指令即时更新目标；施工、移动、生产与拆除计时在恢复后继续（同 §3.3）。
- 视觉：画面降饱和 + 顶部"已暂停"常驻标识；光标与放置预览正常显示。
- 难度语义：操作上限 = 规划质量，不是手速；这直接服务"轻 RTS"与建造优先身份。
- 战役教学关可限制暂停。

## 3. 建造热键栏与放置模式

### 3.1 热键栏（TAB 式）

- 屏幕底部热键栏，三个分类页签：核心经济 / 防御 / 生产指挥（同 building-economy.md §2 分组）。
- 每页签至多 6 个槽位，槽位键固定 **Q W E R T Y**；页签切换键 **[ ]**（数字键已归编队）。
- 槽位显示：图标、造价；钱不够时暗淡；未解锁建筑灰显、仅标"未解锁"。
- 按槽位键进入放置模式；槽位键作用于**当前页签**，切换页签后同一键位对应其他分类（实现从简，不做跨页签组合键）。

### 3.2 放置模式

- **幽灵预览**：半透明建筑跟随光标；逐格有效性着色（绿/红），红格旁浮标原因——按 building-economy.md §3.2 顺序：地形 → 覆盖 → 重叠 → 电力 → 容量 → 资源（标明缺币或哪种料）。
- **覆盖可视化**：进入放置模式即高亮当前供电覆盖边界（对应 building-economy.md §8）。
- 左键 = 下单（付款、开始施工）；**下单后保持放置模式**，可连续下单；ESC / 右键退出。
- **拖拽连放**（装甲墙、中继节点）：按住左键拖出线段，逐格校验、无效格跳过、总价实时预览；松开 = 批量下单。
- 拖线期间镜头不自动平移（边缘不触发滚屏）——超长防线分段放置，是已知限制，不做自动跟随。
- 放置模式与小地图/编队不冲突：小地图左键跳镜头、放置模式保持；F1 跳主脑亦保持。

### 3.3 战斗与暂停中的建造

- 波次中可下单（战斗建造）：靠"下单即阻挡 + 血量爬升"生效。
- 暂停中可下单：钱与占用即时结算，施工进度在解除暂停后推进——排程决策移入暂停，是"规划质量定胜负"的主要载体。

## 4. 选择与信息面板

### 4.1 混合选择

- 允许建筑与单位混合框选；面板以建筑为优先显示主体（基地是玩家的第一关注）。
- 右键指令只作用于选中的**单位**；纯建筑选中时右键无指令语义（防误触）。
- 单纯左键点建筑 = 选中并显示面板；框选不会选中敌军（标准）。
- Shift 点选/框选追加，Ctrl 点选切换；框选从地图开始，拖到 HUD、失焦或离窗取消本次选择，期间不边缘滚屏。几何白模的屋顶也可点选。

### 4.2 建筑信息面板

- 施工进度与当前血量分条显示，另有状态图标（施工中 / 停机 / 升级中 / 运行 / **已摧毁·基座**）；合并呈现留战斗反馈阶段评估。
- 身份信息：造价、产出/射程等关键参数槽的当前值。
- 操作按钮：**维修开关**（被攻击后进入交战状态，周边 6 格内有敌军期间自动暂停，面板显示"交战中"）、**拆除**（部分退款）、**升级**（二幕起）；按钮灰显附原因（钱不够/容量不够/幕未解锁）。
- **选中基座**：主按钮变为**重建**（支付全额 50%，按施工时长推进）；拆除按钮变为**清除基座**（无退款，X 键同样进入确认框）。
- **一键修复**（建造热键栏右侧）：全部建筑脱离交战状态时可用，一次为所有受伤完工建筑开启维修；灰显原因三类——没有受损的完工建筑 / 有建筑交战中（周边 6 格内有敌军）/ 本局已结束。基座重建不在一键范围内。
- 停机建筑点击面板可溯源：跳到断供的中继节点（对应 building-economy.md §8）。

## 5. 单位操控（混合范式的经典侧）

- **右键**：点地面普通移动，途中优先赶路；抵达后待命，只对实际射程内、可见且视线畅通的敌人原地开火，不主动追击或绕障找射击位置。点敌人则为显式攻击目标，可追击。
- **A 键攻击移动**：A+左键，沿途自动索敌。理由：防守补位与"从塔转向调兵"的精英交接都靠它，没有它玩家只能挨个点目标，微操上升。
- **待命开火**：卫兵射程 4 格；目标离开射程、进入迷雾或被地形挡住时立即放弃，继续守位，可改打其他射程内目标。A 移执行期间保留 6 格主动索敌与追击，结束并转为待命后也遵循原地开火规则。
- **编队**：Ctrl+数字保存，数字召回；400ms 内连续两次 Ctrl+同一数字，选中同类建筑并存入该编队。重开/切换训练场清空编队，实体消失后剔除失效成员。
- **集结点**：选中组装厂/重装工厂时右键 = 设集结点；作为 §4.1 纯建筑右键无指令语义的生产建筑例外。
- **自动抵达队列**：移动/A 移按部队中心到点击位置的大致方向安排紧凑行列，横排垂直于行进方向；明显绕障时参考终点附近的进入方向。点击位置为队列中心，单位按当前相对位置匹配独立落点。小幅改点优先沿用偏移；原后排可在掉头时成为新前排。途中不先原地排齐、不逐帧重排，通路优先，到达后恢复目标排列；地形受限时修正无效落点。
- **单位朝向**：行进中按实际位移朝向，抵达后朝计划前方，交战时朝攻击目标；选中单位的箭头和枪口反映当前朝向，命令落点箭头反映抵达朝向。朝向仅用于表现，不引入侧背伤害或新姿态操作。
- **无姿态、无主动技能**：不引入 Hold Ground/Aggressive 切换、不引入任何需点击释放的技能。自动索敌规则由战斗稿定义，操作层不提供开关。

## 6. 镜头与小地图增强

- **F1 = 跳主脑**：核心永远一键可达，服务"核心是最终锚点"。
- 缩放上限放宽到"基地全景"档（一屏看全一幕基地），为建造规划服务；**远景档是第三幕区域层的入口钩子**（同一世界、两种粒度经缩放切换——先留接口，不做内容）。
- 小地图增补（设计目标）：供电覆盖边界、主脑常亮图标；雷达预警方向在小地图以扇形/箭头提示（预警内容见 waves-enemies.md §6，此处只定呈现位置）。
- **当前接入（2026-11-07）**：左下角小地图已实现——地形三色、三态迷雾、敌我/矿点/主脑点阵与镜头视野框，左键点击/拖动跳镜头（放置模式保持），M 键或按钮切换全屏，Esc 优先退出全屏；全屏态预留为将来区域管理主界面（"指挥节点"构想见开发计划 M10 记录）。供电覆盖着色与雷达扇形仍待后续批次。检查边界见[小地图检查](../validation/minimap.md)。

## 7. 快捷键总表

| 键 | 功能 |
|---|---|
| 空格 | 暂停切换 |
| Q W E R T Y | 当前页签建造槽 1–6 |
| [ ] | 建造页签左右切换 |
| A + 左键 | 攻击移动 |
| F1 | 跳主脑 |
| M | 小地图全屏切换（Esc 优先退出全屏） |
| Ctrl+1–9 | 编队；建筑上二次按 = 全选同类 |
| 1–9 | 召回编队 |
| ESC / 右键 | 退出放置模式 / 取消（全屏小地图时先退全屏） |
| X（选中建筑） | 拆除 / 清除基座（进确认框） |

## 8. HUD 布局槽位

- **资源条**（内容已定、**定位待 UI 设计轮拍板**，两案候选）：
  - 内容六项：算力币（含产率）、算力容量 当前/上限、电力 余量/上限、矿石、金属、稀有（对应 building-economy.md §8、resources.md §2–§4）。
  - 候选 A（底部）：贴建造热键栏左端同一横排——花费决策发生在热键栏，读数放同区眼动最小。
  - 候选 B（侧边）：右缘竖条（编队图标上方）——六项竖排最从容，代价是离热键栏远。
- **顶部中**：波次槽位——当前幕、下一波倒计时与**强度预告位**（兑现 game-design-concept.md §7"提前告诉玩家下一波强度"；内容见 waves-enemies.md §6）。
- **顶部右**：暂停指示 + 菜单。
- **底部**：建造热键栏（左）、选中信息面板（中）、编队图标（右）。
- 超载 / 断供 / 预警的警报：屏幕边缘脉冲 + 对应资源条/图标高亮，不用弹窗打断。

## 9. 微操底线核对（对 game-design-concept.md §11）

- 无需操作：自动索敌、并行施工、被动产出、暂停建造。
- 低频操作：拖线建墙、A 移补位、F1 跳主脑。
- 不存在：技能释放、姿态切换、微操拉扯（无碰撞伤害/背刺等机制依赖）。
- 结论：通关所需操作强度 = 规划 + 少量补救性指挥，符合底线。

## 10. 非目标

- 不做姿态系统、主动技能、阵型指令。
- 键位重绑定与冲突检查优先复用已有模块，采用结论见复用调研；不额外自研键位编辑器。
- 不做画面内画线/贴图指挥标记（塔防式路径指示不做——机潮不按你的线走）。
- 区域层操作（授权、委任、求助）不在本稿，等三幕内容稳定后单独推演。

## 11. 基础设置（当前实现）

顶部“设置”或 F10 打开，Esc/取消丢弃草稿并返回；应用后立即生效并保存，恢复默认只修改草稿。首版包含窗口/全屏、垂直同步、60/120/144/240 FPS 或不限帧、镜头移动速度/缩放灵敏度 50%–200%、边缘滚屏。移动速度影响方向键与边缘滚屏，中键拖图保持跟手。

打开时取消进行中的框选、墙线、建造放置、A 移选点与拆除确认，阻断战场键鼠输入和镜头移动。只冻结模拟，不暂停整个场景树；关闭时仅恢复打开前正在运行的会话，原先暂停或已经结束的会话保持原状。视图设置跨重开/训练场切换保留，与模拟存档无关。
