## 1. 目标与边界

按 **首个可玩切片 → 三幕闭环 → 区域指挥** 推进。规则归[系统专稿](README.md)，参数归[数值稿](values.md)，技术边界归[代码架构](architecture.md)，来源与采用理由归[复用调研](reuse-research.md)。本计划只维护实现状态、依赖和剩余工作。

首切片目标：手工灰盒地图，币/矿石经济、固定主脑供电与覆盖、建造与采矿、卫兵生产与指挥、游荡敌/噪声/感疫、普通波次与首次原型机、雷达/迷雾/小地图，以及可重开的胜负闭环。

首切片不接入金属/稀有资源链、能源站/中继、建筑与主脑升级、区域委任或战役。完整单局在幕内循环波次，首切片使用有限编排验收精英交接与清场胜利。

## 3. 待验收与待明确项

- **账本与建造**：暂停批量下单不超支；任一资源不足不部分扣款；取消不重复退款；拆除逐资源按实付退款。施工受伤不倒退进度，带伤完工不补满；维修缺币等待且不积累欠费。容量超载时仅允许符合规则的恢复设施新增。
- **采矿**：矿点占地/覆盖/绑定校验一致；取消/被毁/拆除释放绑定；整分钟产率与整数余数对账；不超采、不负储量；耗竭后拆建不刷矿，重开恢复初值。临时小储量验收后恢复正式配置。
- **空间与输入**：缩放/中键平移后拾取一致；HUD、失焦、离窗与取消不遗留墙线/框选；建筑完工时正确移出单位和敌人，边缘无空位则等待；移动不穿建筑或障碍。
- **生产与指挥**：队列上限、付款/占容/取消、出厂不二次占容；出口受阻保持队首 100%，打开后仅出一兵；主动拆厂退订单、被毁不退；集结不可达待命；A 移目标死亡后续行。
- **生命周期**：暂停可下令而时间/生产/移动/冷却不推进；重开和场景往返清空队列、单位、编队、噪声、波次、矿点绑定及原生回调状态；训练预置建筑不产生实付退款。
- **威胁与战斗**：封墙/破墙/缺口分流、目标死亡重选、游荡与回填、噪声聚拢/滞留、感疫产量与豁免、炮塔射程/曳光/冷却，以及首精英前经济与生产窗口。
- **规模与设计**：记录基准机器和模拟/渲染/寻路耗时；M6 前明确雷达提前量、事件推送通道；M8 前明确动态电网的赤字与恢复规则；M10 前补齐授权、预算、蓝图与求助规则。

参数取[数值稿](values.md)，不保留旧版操作或旧数值验收表作为执行依据。

## 4. 后续里程碑

### M0：规格与模块选型（持续）

敌种、预算曲线、噪声、感疫和接敌参数已进入数值稿；继续明确后续兵种、图池/矿点配合、雷达与规模预算。新模块按复用流程逐项核对来源、许可、依赖与适配限制，不把候选写成已接入。

### M5：完成威胁与防守闭环

保留现有独立 `wave_director.gd`、`threat_system.gd`、`enemy_system.gd` 和 `tower_system.gd` 接线。`damage_entity` 死钩子已删除；主脑失败后冻结时钟、停用原生移动、拒绝本局操作，重开/切场景恢复新会话。继续统一伤害结果与死亡处理，补验终局后的重开和场景往返。

`main.gd` 已改为状态信号仅标脏、原生 `_process` 每帧至多发布一次完整快照，交互与绘制共享最近发布状态；命令仍实时校验。静态地形使用 SubViewport.UPDATE_ONCE 缓存，新会话重绘，普通占用变化复用纹理。标准开局全景同机不限帧对照：28,341 → 272 次绘制调用/帧，稳定约 18–19 → 440–470 FPS；保留 `--perf` 诊断。下一步记录加量耗时，并按架构目标推进分区休眠、视野外降档与降速阀；开局测量不代表支持目标规模。

验收：封墙不迷向、破墙后继续推进；感疫只对规定资产触发，主动拆除/取消不产敌；施工受伤、维修与正式战斗可正确结算；暂停有效、威胁可读。

### M6：视野、情报与首次精英

接入三态迷雾、实时视野、覆盖探索、视野外降档、雷达、小地图、正式波次/警报/胜负 HUD、QWERTY 建造分类与键位重绑定；解决 R 建造槽和重开键冲突。

动工前明确事件通道：实现架构稿事件总线，或按现行“信号 + 读模型轮询”修订目标架构，确保视野外事件可以推送警报。基础预告给粗方向，雷达提供更早预告与精确扇形，不显示数量/构成。

补齐原型机电磁庇护与跨墙，沿用已接入的对建筑高伤害。首切片预设波次全部出完、无待出生敌人且清场后判胜。

验收：精英逼出调兵且留有反应窗口；视野外事件仍有警报；小地图、放置、单位与编队输入无冲突。

### M7：体验迭代

按[基础设定](game-design-concept.md)验证建造乐趣、静默期张力、首波压迫、精英交接和失败可读性。能连续玩到胜负并留实际观察记录，再推进三幕；调参写回系统稿与数值稿。
