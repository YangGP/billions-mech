# 开发计划

> 版本：1.0。日期：2026-11-05。M4 单位生产与指挥已接入，28 个脚本语法、双场景启动及 1920×1080 白模画面检查通过，人工交互仍待验收。证据见 [M4 记录](../validation/m4-units-production.md)；后续从 M5 威胁与防守继续。

## 1. 目标与边界

按 **首个可玩切片 → 三幕闭环 → 区域指挥** 推进。体验以 [基础设定](game-design-concept.md) 为准，规则归对应系统专稿，建筑/资源初值归 [数值稿](values.md)。本计划只维护交付范围、依赖与验收，不维护第二套规则或数值表。

技术边界见 [代码架构](architecture.md)，模块采用与候选见 [复用调研](reuse-research.md)。

### 已采用规则与后续边界

以下规则已写入对应资源/建造/地图专稿并接入本轮代码，动态电网等后续项除外。

| 事项 | 本轮方案与后续边界 |
|---|---|
| 矿点绑定 | 采矿站 2×2，占地包含对应矿点锚格；一站一矿，下单时绑定，取消/被毁/拆除完成时解绑。普通建筑不得覆盖未耗竭矿点，矿点本身不挡通行 |
| 矿点生命周期 | Resource 保存初始储量，sim 独立保存剩余量；耗竭后隐藏矿点表现并保留耗竭状态，整局重开才恢复。采集不得超过余量，停产期间不积攒补发产量 |
| 退款与维修 | 实体保存逐资源实付额；取消按实付全退，拆除逐项乘退款比并向下取整，被毁不退。维修只耗币，速率按数值稿，缺币不追扣长时间欠费 |
| 施工血量/进度 | 本轮保留 M3 独立数据与现有双条显示，保证受伤不倒退进度、带伤完工不补满；设计稿的合并显示在战斗反馈阶段再明确 |
| 超载恢复 | 本轮沿用 M3：既有运行继续，仅零占容的容量恢复设施可新增，仍检查其他条件。容量口径修正为：占容资产释放降低占用，节点损失降低提供 |
| 电力供给损失 | 本轮仅固定主脑供电；能源站断供/被毁后的赤字与恢复规则留 M8 前明确 |
| 操作范围 | 保留现有镜头、连续放置与墙线；采矿站增加建造按钮，暂不占用 R 重开键。正式分类热键栏仍在 M6 接入 |

### 验收与进入 M4 的条件

- **账本一致**：资金/矿石任一不足都不部分扣款；取消不重复退款，拆除不因内容数值修改而多退；墙线预览与实际下单的费用、跳过格一致。
- **时间正确**：主脑保底与节点产币、采矿站产矿按完整运行分钟对账；施工、暂停、拆除、满血/缺币维修不额外产出或扣款。
- **矿点正确**：错矿/重复绑定/普通建筑覆盖矿点被拒绝；取消释放绑定；采集不负储量；耗竭后重建不刷矿；重开恢复初始储量并清空绑定和余数。
- **操作可读**：可从开局完成节点、采矿、炮塔建造及取消/拆改；暂停中可下单，恢复后推进；多格覆盖、阻挡和重开不回归。矿点同时可在编辑器预览与运行中识别。
- **检查与记录**：遵守 AGENT.md，不写测试脚本；运行 GDScript 语法、资源导入与启动检查，人工结果写入实施记录。耗竭可用临时小储量配置验收，交付前恢复正式地图，不能把未执行项记为通过。

M3 人工验收继续保留，M4 已按用户后续指示推进，不能以新功能接入替代旧功能验收。基础卫兵规格与生产边界现已补齐；首次精英前的生产窗口随 M5 经济/波次推导验证，旧短波次表不复用。

### M5：威胁与防守闭环

接入普通敌、游荡敌与边缘回填、噪声聚拢、首波触发、波次预算和基本预告。机潮采用流场行军与局部接敌寻路，实际建筑阻挡、索敌/分离使用空间分区；接入敌人视觉/LOS 与接敌切换。

统一炮塔/单位/建筑伤害与死亡，按威胁稿接入感疫和噪声脉冲；补齐主脑失败、胜负停止和重开。感疫换算比未明确前不用任意常数作为正式规则。

验收：封墙不使敌人失去行军方向；破墙后继续推进；感疫仅对规定资产触发，拆除/取消不产敌；威胁可读且暂停有效。补验 M3 的受伤施工与维修。逐步加量记录模拟/渲染/寻路耗时，按架构方案接入分区休眠与负载降速；目标规模未通过实测前不写成已支持。

### M6：视野、情报与首次精英

接入三态迷雾、覆盖探索与实时视野源，与迷雾外降档同批交付。补齐雷达、小地图、QWERTY 分类建造栏、状态面板、错误原因与正式胜负反馈；确定资源条布局，处理 R 建造槽与现行重开键冲突。键位重绑定/冲突检查按选型结果接入。基础预告始终给粗方向，雷达提升方向精度和提前量，不显示数量/构成。

原型机按威胁稿接入电磁庇护、跨墙、高建筑伤害。预设波次包含首次精英，全部出完且清场后判切片胜利。

验收：视野外事件仍有警报；雷达收益明确；精英逼出有效调兵且有反应窗口；小地图/放置/单位/编队输入无冲突；无待出生敌人时才可胜利。

### M7：体验迭代

验证基础设定 §13 前五项：建造乐趣、安静期张力、首波压迫、精英交接、失败可读性。调参写回数值与系统专稿，避免两套标尺。

验收：能连续玩到胜负，无阻塞问题，五项均有实际观察记录。循环未成立时继续迭代切片。
