# M6 视野迷雾实施与检查

> 历史技术专题：文中“当前”指记录对应的版本。保留实现来源及当时证据，不继承为0.5.89功能/数值/人工验收。现行规则和待办见[开发计划](../docs/development-plan.md)，最近检查见[0.5.89记录](review-fixes-0.5.89.md)。


更新：2026-11-07，0.5.11-dev。仅视野迷雾首批完成，M6 全部内容及完整玩法尚未验收。

## 接入内容

- `sim/vision_system.gd` 维护未探索/已探索/可见三态，供电覆盖与实时视野共同扩展永久探索；重开和切场景重建。
- 主脑、卫兵、运行且通电的炮塔提供 12/7/10 格实时视野；验证实体提供 7 格。建筑/单位 Resource 保存半径，施工、停电、拆除或死亡失去视野。墙、算力节点、组装厂与采矿站不额外提供视野。
- 地形 LOS 使用 supercover 格线遍历，阻止岩体和对角缝隙穿透；首个阻挡格本身可被看见，建筑与崎岖地不挡。单位与炮塔射击共用地形遮挡规则。
- 快照移除不可见敌人及未知矿点；悬停、建造预览与地标不泄露未知地形。追击失去目标后搜索最后看见的位置，无法通过敌人 ID 指令攻击黑/灰区目标。
- 视野源跨格/新增/移除时才合并视野，静止源复用 LOS；迷雾版本改变时才更新单张投影纹理。纹理按真实地图多边形裁剪，覆盖地图边缘残片，地标与静态地形缓存分层。
- 远离己方资产且不可见的敌人将感知/游荡决策间隔及噪声寻路重试间隔放宽四倍；移动/碰撞/冷却/伤害仍逐 tick 结算。己方资产附近、受击、接敌与重回视野时恢复正常响应。未实现分区休眠、精简流场或整体降速阀。
- 保留波次文字预告；感疫新增粗方向文字警报。当前使用状态信号与警报序号快照，不提供事件历史、精确位置或敌人数量。

## 检查证据

| 检查 | 结果 |
|---|---|
| Godot 4.7.2 原生导入 | 无项目解析/依赖编译错误，新增全局类正常注册 |
| 全部 40 个 GDScript（含 vendor 与检查脚本） | 逐文件 `--check-only --script`，0 失败 |
| 可重复行为检查 | `godot --headless --path . --script validation/vision_checks.gd`：49 项检查、0 失败 |
| 标准开局 / 训练场 | 各 `--headless --fixed-fps 30 --quit-after 600`，退出 0，无项目脚本错误 |
| 原生图形 | GL Compatibility、RTX 4080 SUPER、1920×1080；检查标准开局、全景、远处侦察、撤回后灰区、训练场画面；黑区遮挡、灰区记忆、己方单位/建筑层级正确，未知地标无外露 |
| 补充边缘检查 | 图形检查发现并修正边界蓝色残片和“侧翼”标签外露；修正后重新导出并查看 |

行为检查涵盖覆盖探索与断电后记忆、崎岖/岩体/对角遮挡、静止缓存、建筑不挡视线、重叠视野源、施工/断电/移除、炮塔共享视野仍受 LOS 限制、隐藏敌人的指令/自动索敌、未知矿点/悬停/放置预览、最后位置追击、正常移动与降频计时、回到视野恢复寻路、敌方感知独立、暂停/重开/切场景/失败、侦察重新发现目标和感疫警报清理。

本机临时证据位于 `.godot/vision-checks.log`、`fog-import.log`、`fog-standard.log`、`fog-training.log`、`fog-render.log` 与 `fog-*.png`，不提交生成缓存。引擎仍报告受限环境的根证书读取错误和 Steam 编辑器全局设置保存错误，未影响项目检查与本地渲染。

## 验收边界

己方建筑由己方账本提供当前信息；地形静态不变，已探索后持续保留。当前没有敌方静态建筑，未增加其最后观测快照系统。移动源按格更新，不包含平滑边缘或逐像素视野。

雷达、小地图、正式事件历史/警报 HUD、精英能力与有限波次胜利尚未实现。实际鼠标键盘侦察/交战手感、长局噪声追踪、连续平移缩放及千级敌人性能仍待验收；脚本与画面通过不等同于完整玩法或性能验收。
