# 移除旧2D战场（2026-11-11）

按用户授权移除旧2D战场，不改变二维逻辑地图、导航、HUD、小地图或暂缓3D迁移的肖像。

## 清理内容

- 删除 `scenes/main.tscn` 及专用的2D相机、地形、迷雾和覆盖脚本及UID。
- 旧 `foundation_view.gd` 缩减为 `portrait_view_2d.gd`（MechPortraitView2D），保留原有肖像形状绘制与UID；移除战场拾取、选择/路径/集结点/光标、矿物、群体效果和地图编辑预览。HUD改为传递单对象快照。
- main、选择与建造控制器显式依赖3D类型，移除2D拾取和相机能力回退、旧 `--3d` 场景重定向；唯一入口仍是 `scenes/main_3d.tscn`。
- HUD缩放阈值引用3D相机；MechIsoGeometry保留小地图和肖像所用的投影/格子/脚印/包围盒方法，删除仅旧战场使用的两个方法。
- 更新当前入口、接口、迁移和交接文档。历史验证记录保留原条件，不能再按其中旧2D启动命令运行当前工作区；需要旧代码时从Git历史恢复。

## 验证

Godot 4.7.2 导入未见脚本解析错误；57个活动脚本（含vendor）逐一 `--check-only`，失败0；既有视野回归49项、0失败；默认3D无头与原生OpenGL渲染各启动180帧，未见脚本错误。原生短时渲染覆盖初始选择与肖像绘制，不等同于人工交互验收。日志：`.godot/remove-2d-{import,parse,vision,startup,render}.log`，逐脚本日志按次覆盖，终端保留57项汇总。

静态核对现有场景/脚本引用，已删除的脚本与类不再被运行代码引用；HUD肖像脚本与场景资源路径已切换，小地图和二维模拟/导航保持依赖完整。根证书读取、外部Steam编辑器设置保存提示单独记为环境错误。

没有新增测试脚本。真实鼠标/键盘、其他肖像状态的视觉复验、完整单局和综合性能仍按[人工清单](3d-manual-checklist.md)继续验收；删除旧入口不代表这些项目通过。
