# M4：单位生产与指挥

日期：2026-11-05。版本：0.4.0-dev。保持 1920×1080，全部采用几何白模；未新增测试脚本。

## 已实现

- 组装厂 3×3、独立 5 格队列，卫兵参数来自 [数值稿 §10](../docs/values.md)。生产下单付款并预留容量，出厂只转移占用；取消全额退款，队列和单位损失释放相应容量。
- 工厂停机/拆除暂停队列，已付订单不因容量超载暂停；出口受阻时队首保持 100%，有空位后出厂。主动拆除完成退未出厂订单全额，工厂被毁则订单不退款。
- 工厂右键设置集结点；边缘相邻空格出厂，附近单位中心过近时换位或等待；集结点不可达则出厂待命。
- 客户端选择与编队，点击单位/建筑白模屋顶、地图框选、建筑/单位混选、Shift 追加、Ctrl 切换；建筑信息优先，右键只给混选中的单位下令。纯工厂右键设置集结点，验证实体须先选中才可移动。
- Ctrl+1–9 保存，1–9 召回；400ms 内连续两次 Ctrl+同一数字选中同类建筑。失焦/离窗/HUD 释放取消框选；重开、切场景清空选择/编队/手势，失效实体从选择与编队移除。
- 单位移动、指定目标攻击、A 移和待命自动索敌；移动优先赶路，A 移交战后恢复原目的地，指定目标消失后待命。攻击有模拟步冷却、射程、障碍地形视线、伤害与白模射击反馈；训练靶静止、不反击、无击杀收益。
- 原生 AStarGrid2D 路径共用建筑与地形阻挡，崎岖减速；整组指令无足够可达位置时拒绝整单，保持原指令。初版的移动格桶硬阻挡与友军整格重寻路已由下述 0.4.1 修正替代。
- 新增资源配置的“单位训练场”：一厂、两节点、四名卫兵、两训练靶，250 币/50 矿石。可从顶部按钮切入/返回标准开局，或 `run.bat -- --training` 直接进入；R 重开当前场景。标准开局没有额外正式部队。
- 场景切换先在临时网格校验 Resource、初始建筑/单位/训练靶、矿点与覆盖，成功后重建状态。生产、集结点、单位指令和场景切换均经统一命令入口。

## 0.4.1：训练场窄口与原生 RVO 接入（2026-11-06）

用户反馈：单位容易卡在主脑与组装厂之间。源码检查发现友军硬阻挡、整格封路重寻路、重算时返回当前格心，以及攻击每半秒覆盖路线会共同加剧窄口拥堵。

- 自写侧让、两轮软分离和贴墙滑动算法已删除；直接调用 Godot NavigationServer2D 的 RVO2 求解器。`crowd_navigation.gd` 只负责 API 适配、回调批次及 RID 生命周期，没有自行求解避让速度。移动/待命原生优先级为 0.5 / 0.2；出生仍检查间距，同批阵型采用不同格心。
- 单位作为原生避让 agent，建筑/地形阻挡格按行合并为原生静态 obstacle，地图边界也注册为障碍；移动结果再以同一圆形身体检查静态位移。训练场建筑位置保持原样。
- 新路径在下一段可安全直达时跳过起始格心；中间路点采用 0.3 格容差，并检查到下一路点的静态通路。最终到达容差为 0.08 格，不强制瞬移到格心干扰原生避让。
- 阵型落点优先分给近处单位，减少按实体编号分配造成的交叉；攻击只在没有路径或原攻击落点失效时重算，友军仅占用/预留攻击落点，不再封锁沿途整格。
- 原生回调收齐后批量提交移动，再按路点进展计数；失败重算保留堵塞记录并限频。只有批次完成才刷新该模拟步的视图，回调次序不决定单位提交结果。
- 暂停使待收回调失效并停用地图；命令作废旧批次，重开/切场景/退出释放 agent、obstacle 和地图；瞬移同步原生位置并清零速度，普通移动不强制覆盖内部速度。
- 追加反馈修正：友军占位不再筛掉点击格或替换阵型终点；单兵只接受点击格心，静态不可达则拒绝整单。成组落点下令时按静态可达性分配一次，后续避让和堵塞重寻路保持各自原定目标。
- 最后路点仅在本帧原生位移提交后确认到达；临时无路径或被挤离但尚未结束的移动/A 移会限频重试原目标，不直接切待命。等待时仍显示原目标标记，A 移交战时也保留原行军目标标记。

本次遵守 AGENT.md，不新增测试脚本；29 个 `.gd` 的 Godot `--check-only --script` 语法检查通过，`git diff --check` 通过。没有对这次修复执行点击试玩或运行验收。官方提示 RVO 的完全对称迎面情形仍可能失败，不能仅凭采用成熟求解器宣称通行已验收。

优先人工复验：四兵从厂西侧经主脑南侧一格通道向东移动，再反向返回；拆成两队相向通行；让一兵待命堵路、其余三兵穿过；在窄口附近反复右键换向及 A 移/集火；生产新兵集结经过该通道。观察是否持续向目的地推进、是否穿建筑/地形、待命让路后是否保留指令，以及交战后 A 移是否续行。移动中暂停、暂停下令/建造、恢复、R 重开、切换场景和关闭窗口，复验没有旧回调导致的额外移动或原生资源残留。

追加人工复验：单选一兵，点击被待命友军暂占的可走格，确认目标标记仍是点击格；友军经过终点附近时不能在未到达处提前停下。成组下令后让其他友军横穿路线，确认各自终点标记不变；临时路径中断并恢复后继续原目标。此项尚未执行实机验证。
