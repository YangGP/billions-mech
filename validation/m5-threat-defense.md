# M5 实施与检查

更新：2026-11-06。当前为 M5 0.5.6-dev，保持 1920×1080 几何白模。规则与数值分别以[系统专稿](../docs/README.md)和[数值稿](../docs/values.md)为准，后续安排见[开发计划](../docs/development-plan.md)。

## 当前实现

| 模块 | 实际接线与边界 |
|---|---|
| `sim/enemy_system.gd` | 波次敌人行军/接敌/追击、建筑阻挡攻击、地形 LOS、游荡与噪声聚拢；接敌与分离使用网格桶 |
| `sim/march_field.gd` | 项目自有加权场，地形权重 × 建筑软成本；主脑豁免，占用变化重算，HP 漂移限频刷新 |
| `vendor/crusade/steering.gd` | 直接复用的分离与速度合成，锁定 `e4929c8`，MIT 随附；均匀成本 flow_field 未保留在工程 |
| `sim/wave_director.gd` | 时间/节点发展度触发、定性与粗方向预告、边缘出生带、预算构成与窗口内流式放兵；预告纳入放兵起点之间的间隔 |
| `sim/threat_system.gd` | 游荡敌开局散布、边缘回填、战斗/施工/运转/移动噪声、占容资产感疫；主动拆除和取消不触发感疫 |
| `sim/tower_system.gd` | 已完工且通电的炮塔自动索敌，伤害结果交回 SimCore；射击数据经建筑快照驱动曳光，完整视野/LOS 门控待 M6 |
| 内容与表现 | 四敌种 Resource；标准开局开启威胁，训练场关闭威胁；敌人白模/血条与临时文字预告 |
| 会话失败 | 主脑移除锁定 defeat，暂停既有时钟、停用原生移动；清理该次攻击已死亡单位后跳过炮塔/移动阶段；只允许重开与切场景，禁止继续建造/生产/暂停恢复/下令 |
| 表现更新 | 状态信号只标脏，原生 `_process` 统一发布一份完整快照；选择/拾取/绘制复用，暂停/场景信息采用廉价查询；失败面板提供重开与场景入口，保留镜头查看 |

敌人使用独立移动链路，保持 `rvo_speed=0`；玩家单位继续直接使用原生 AStarGrid2D 与 NavigationServer2D/RVO。游荡敌的建筑噪声寻路复用建筑追击落点，避免把实心占格作为 A* 终点。

SimCore 负责付款/占用/容量、伤害与移除的业务接线；建筑死亡不退款、被毁工厂不退订单；重复索敌跳过同 tick 已死亡单位，避免重复感疫。完整修复清单见[逐提交审查](m5-bundle-review.md)。
