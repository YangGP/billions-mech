# 表现层输入拆分（2026-11-10）

按用户决定，仅拆分已确定的选择/编队与建造手势；维修站、驻军/合同、区域自动化的模拟模块划分暂缓，待玩法确定后再评估。此前两项逻辑修复保留。

## 变更

- `main.gd` 从1157行降至718行，保留场景接线、快照发布、全局快捷键和事件优先级。
- `MechSelectionController` 持有 MechSelectionState、框选、双击、编队时序和攻击移动状态；负责拾取、选择展示及单位指令。新 generation 清理选择和时序，按同一快照裁剪存活实体和驻军编队。
- `MechBuildController` 持有建筑类型、键盘光标与墙线端点；负责预览、键鼠切换、墙线提交及取消。继续复用核心预览接口、Geometry2D.bresenham_line 和 CommandQueue。
- 两个控制器均为组合根持有的 RefCounted；显式装配依赖，不读取 main 的私有字段，不额外注册输入回调或复制快照。2D/3D继续共用同一输入入口与相机接口。

输入优先级仍由 main 维护：设置屏蔽战场，Q/W/E与键盘建造先于HUD焦点，活动框选/墙线接收释放，未处理输入再交相机和点选。失焦、离窗、设置、重开和终局沿原入口取消未完成手势。拆分不增加新玩法或依赖，不承诺帧率提升。
