# 0.5.49 外部审查优先项修复记录

2026-11-08。针对[逐提交审查](review-0.5.48.md)的优先问题做代码修复；未声称原生验收完成。

## 已修

- **F01 统一科技/主脑门槛**
  - `BuildingDefinition` 新增 `required_tech_level` / `required_mainbrain_level`。
  - 中级建筑/升级目标补齐 II 级前置；III 级目标补齐 III 级前置。
  - catalog、建造预览、下单、升级、工厂新增订单统一查询当前运行科技/主脑。
  - 既有合法队列不被删除，只阻止新增高级订单。
- **F02 假开放/闸门**
  - 闸门改为玩家路径/RVO可通行、敌方路径/局部场仍阻挡；合金门继承。
  - 驻防碉堡/远征接驳站因行为未实现改为不可建造，菜单显示未开放。
- **F03 合金墙身份**
  - 新增 `is_wall_like()`，墙体身份覆盖装甲墙/合金墙，用于敌方局部场、索敌、顺路排除、墙连接。
- **F04 自动维修**
  - 在任务ID、预算授权/花费、手动接管实现前禁用自动执行，避免零预算/重复开启扣款。
- **F05 可通行设施重建**
  - 陷阱/减速栅重建时恢复可通行；门重建恢复玩家通行、敌方阻挡。
- **F06 地雷庇护**
  - 爆破伤害走统一庇护源检查。
- **F07 电磁减速**
  - 敌人使用实例最强减速倍率，不再固定0.4；到期重置。
- **F08 光环取整**
  - 光环倍率改为百分比（115/80/120），修复15%被取整成20%。
- **F12 升级UI校验**
  - HUD升级错误与命令校验共用科技/主脑前置。
- **F14 升级/重建工期**
  - 定义替换与重建时刷新施工/拆除tick。
- **F15 强化环境取整**
  - 先计算基础电量再乘倍率并封顶，避免先乘后除的取整偏差。

## 追加修复

- F09：冷却光环已进入预览、施工、升级、重建和最终结算的同一有效需求查询。
- F11：雷达只在普通预告前额外20秒窗口公开方向，按权威出兵时间计算。
- F13：燃料充足时周期结束同tick续开下一炉，升级优先在旧周期结算后切配方。

## F10 部分收敛

- 覆盖脏标记只在主脑/中继等 `coverage_radius > 0` 的定义放置、完工、拆除、毁坏、升级时置位；普通墙/工厂不再触发全图覆盖重建。
- 环境脏标记只在环境电源定义变化时置位。
- 光环改为仅在放置/完工/拆除/毁坏/升级/覆盖变化时重算，不再每次经济重算全源×目标扫描。
- 探索只把新增已探索格交给环境电源刷新；仅重算采集范围与新增格相交的风能/太阳能，结构变化才全量刷新。
- 维修站目标选择改为事件驱动：结构变化、受损或目标满血才重选，不再每tick全建筑扫描。
