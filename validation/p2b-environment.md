# P2b 风能、太阳能与环境采集

2026-11-08，0.5.30-dev。输入基数为 P2a 提交 `1a352a2`。本包同时修正 P2a 遗漏的运行时内容接线：`relay_node`/`cooling_tower` 与新的风能/太阳能一起加入 `development_128.tres`。

## 实现

- 新模块 `sim/environment_energy.gd`：
  - 采集区：本体外扩 3 格（风能 7×7、太阳能 8×8）。
  - 分数：风能崎岖 2、开阔 1；太阳能开阔 1；本体/障碍/地图外/未探索格排除，已探索灰区计入。
  - 输出：风能 `min(18, score/4)`，太阳能 `min(20, score/2)`；0 输出拒绝。
  - 同类采集区按 entity_id 预约；跨类型可重叠；预约含本体和全部采集区。
- 内容：
  - `wind_station.tres`：1×1，60币/8金属矿，30s，HP250，环境 `wind`。
  - `solar_station.tres`：2×2，50币/6金属矿，30s，HP250，环境 `solar`。
  - 两个定义和 P2a 中继/冷却塔一起加入开发开局数组。
- 运行时：
  - `MechBuildingState.environment_power` 保存实例当前输出，不改共享 Resource。
  - `economy` 对风能/太阳能使用实例 `environment_power`，普通建筑仍用定义值。
  - 下单前预览、`_place`、重建校验共用评分/冲突规则；下单即预约。
  - 拆除/取消/清基座释放预约；基座保留预约；重建不重复预约，并按当前已探索状态重新校验评分。
  - 新探索格使 `VisionSystem.explored_revision` 变化，SimCore 只在该变化时重算环境电源，不随单位每帧扫全图。
- HUD/预览：
  - 建造预览绘制采集区轮廓、冲突格，并显示预计电力。
  - 选中建筑详情显示环境供电。
  - 主脑/中继覆盖仍决定建筑能否运行。
