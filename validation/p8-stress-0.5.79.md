# P8 批量建拆压力模式

2026-11-08，0.5.80-dev。`--stress` 运行参数，仅用于同图性能诊断，正常游戏不启用。

## 模式

- 每 0.5s 交替：
  - 在主脑下方建一条 1 行装甲墙线
  - 拆除首座装甲墙
- 每 4s 把初始单位派往地图四角方向，覆盖探索/视野更新
- 不生成额外敌人，不修改配置
- 配合 `--perf` 输出阶段峰值/最差 tick

命令：

```powershell
godot --headless --path . --quit-after 900 -- --stress --perf
```

## 观察

| 项目 | 结果 |
|---|---|
| 脚本错误 | 修复主脑坐标快照访问后为 0 |
| 稳定 sim 峰值 | ≈3.0ms |
| view 峰值 | ≈6.5–23.8ms（含首批探索路径） |
| native_nav 峰值 | ≈1.9ms |
| frame 峰值 | 8.3ms（120 FPS 上限） |
| 建/拆/派兵命令 | 交替执行，无 SCRIPT/Parse 错误 |

## 边界

- 覆盖批量建拆+基础探索，不含密集战斗、断供/断网、自动化重试。
- 无头模式不能证明渲染流畅；只用于模拟/视图阶段耗时对照。
- 不能据此标记 P8 完成。

## 附带修复

`_state` 快照没有 `mainbrain_origin/footprint`，F7 区域创建、键盘建造初始光标和压力模式会报错；已改用 `SETTINGS.map_definition` 的权威坐标。
