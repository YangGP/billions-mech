# 建造经营系统（建筑与机制）

> 范围：建筑与建造经营机制（敌种、波次编排、寻路索敌、区域层委任见各专稿）。所有可调参数以参数槽占位（§10），调参目标见 §9，数值见 values.md。

## 1. 总览

一句话：**付款 → 自动施工 → 建筑在风险窗口中长成**。资源侧（软通货 + 三种采集资源 + 两个约束，resources.md §2）决定"能建什么、养多少"；本稿回答"建什么、怎么建、怎么运作"。

设计目标（对应 game-design-concept.md §13 验证点）：

- 建造乐趣 ← 选址约束 + 拖拽连放 + 预留扩建空间
- 安静期张力 ← 产币速率 × 建造时间形成排程压力
- 第一波压迫感 ← 在建可被攻击，扩张有暴露期
- 精英交接 ← 升级与军工产能服务"从塔转向兵"（原型机规格见 waves-enemies.md §8.2）
- 失败可读 ← 约束任一吃紧都有明确信号；退款规则可读

## 2. 建筑清单与三幕解锁

### 2.1 核心与经济

| 建筑 | 作用 | 关键决策 |
|---|---|---|
| 主脑 | 核心；基地等级；三幕升级；最终失败条件；提供初始电力 | 何时升级、资源投给升级还是防御 |
| 算力节点 | 提供算力容量 + 被动产出算力币；耗电 | 建几个、放哪、是否扩到墙外 |
| 采矿站 | 贴矿石堆采集矿石（幕一）；采集链入口，造价纯币 | 占哪个矿堆、占几处、离防线多远 |
| 萃取站 | 贴稀有点位采集稀有资源（幕一后段）；服务主脑升级线 | 抢稀有点位的时点、护不护它 |
| 铸造站 | 贴金属矿脉采集金属（幕二）；军备料入口 | 幕二扩张方向被矿脉牵引、护不护它 |
| 能源站 | 提供电力容量 | 电厂数量与位置、优先供电 |
| 中继节点 | 扩展供电覆盖；1x1 占位；低血量；必须从现有覆盖延伸 | 扩到墙外还是缩在墙内、是否做冗余 |
| 冷却站（未来） | 提供冷却液容量 | 人口 / 算力规模 vs 冷却投入 |

### 2.2 防御

| 建筑 | 作用 | 关键决策 |
|---|---|---|
| 装甲墙 | 阻挡、迟滞、引导 | 防线形状、留几个缺口、升级 |
| 哨戒炮塔 | 持续输出；对精英低效 | 覆盖范围、升级、与部队配合 |
| 电磁陷阱 | 区域迟滞，克制快速单位 | 放哪、何时补充 |
| 维修舱 | 持续维修附近建筑，消耗算力币 | 维修还是新建；放哪 |
| 雷达站 | 开视野、预警机潮方向 | 侦察投入、提前知道多少 |

### 2.3 生产与指挥

| 建筑 | 作用 | 关键决策 |
|---|---|---|
| 组装厂 | 基础单位 | 兵种构成、容量分配 |
| 重装工厂 | 载具 / 反精英单位 | 何时转军工、如何配合炮塔 |
| 调度中心 | 解锁委任、蓝图、区域自动化 | 何时把建设交出去、哪些亲自管 |

### 2.4 身份性规则

> 资源约束语义（软/硬约束、断供、级联）见 resources.md §5–§6；此处只列建筑身份。

- **算力节点**：被动产币 + 提供容量；净提供者，不占容量；耗电。
- **采集站（采矿/萃取/铸造）**：必须贴对应矿点建（矿石堆/稀有点位/金属矿脉）；矿点储量有限，采完站停产保留、可拆除部分退款——扩张由储量消耗驱动。**造价纯币不吃料**（采集链入口，避免鸡生蛋）。资源定义与稀有定位见 resources.md §4。
- **中继节点**：1x1 占位；必须从现有覆盖延伸；覆盖可跨地形；本体不可置于不可建造地形。
- **后期自动化**：调度中心按"电网扩展政策"自动建中继节点；不自动取消；玩家可检查、暂停、接管。
- **冷却站（未来）**：随食物机制加入，放进中后期。

### 2.5 三幕解锁

- **第一幕**：主脑、算力节点、采矿站、装甲墙、哨戒炮塔、雷达站、组装厂；**后段解锁萃取站**（服务主脑升级1 的稀有需求）。主脑提供初始电力，算力节点数量受初始电力限制；暂不做能源站和中继节点。
- **第二幕（第一次主脑升级）**：能源站、中继节点、铸造站、重装工厂、电磁陷阱、维修舱、算力节点 / 装甲墙 / 哨戒炮塔升级。
- **第三幕（第二次主脑升级）**：调度中心、主脑要塞升级、高级重装工厂 / 反精英单位；区域层开始委任。

## 3. 建造流程（付款后自动施工）

### 3.1 入口与解锁可见性

- 建造菜单分类：核心经济 / 防御 / 生产指挥（同 §2 分组）。
- 未解锁建筑**灰显，仅标注"未解锁"**，不标注幕数（防三幕内容过早泄露）；可见的下一幕工具制造升级动机。

### 3.2 放置校验（按序报错，空间先于钱包）

1. 地形：可建造地形格。
2. 覆盖：格在供电覆盖内（resources.md §6）。
3. 重叠：无建筑；敌军占位 → 该格无效；友军占位 → 允许下单，完成时挤开。
4. 电力余量：预留后不超容量（resources.md §6）。
5. 容量余量：占用后不超提供（resources.md §5，软约束的禁令点）。
6. 资源：币 / 矿石 / 金属 / 稀有全部足额（任一不足该格无效，报缺哪种——resources.md §2–§4）。

### 3.3 支付与退款

| 状态 | 资源（币 + 矿石 / 金属 / 稀有） | 容量/电力占用 |
|---|---|---|
| 下单 | 全额支付（各资源一起付） | 立即占用 |
| 取消施工 | **全额退款**（各资源全额） | 立即释放 |
| 在建被毁 | **不退款** | 释放 |
| 完工后拆除 | 部分退款（退款比参数槽，各资源同比例） | 拆除完成时释放 |

代价模型：**施工的代价是时间与暴露，不是钱**；钱在完工后才沉没。

### 3.4 施工状态

- 建造时间为参数槽；**所有建筑并行施工**——无全局队列、无施工单位（轻 RTS 底线，所选交互的必然推论）。
- 施工中：HP 从 0 线性爬升至满；可被攻击、可被摧毁——**这是扩张的暴露期，风险窗口的核心**。
- 施工中：不工作（无产出/火力/覆盖），但**物理阻挡从下单起生效**（战斗封缺口的基础）。
- 战斗建造：允许在波次中下单。"快墙慢楼"原则见 §9.1。

### 3.5 拖拽连放

- 装甲墙、中继节点支持按住拖拽连续下单。
- 逐格校验：无效格跳过、不中断；总价实时预览；无单次数量上限。
- 中继连放：前一节**完成后**覆盖才延伸，连续拖拽需等待——扩张节奏由建造时间决定。

### 3.6 拆除

- 已完工建筑可拆除：拆除需时（参数槽），期间建筑停机、不可维修。
- 部分退款；释放全部占用。
- 可取消拆除，建筑恢复原状（血量不变）。

## 4. 建筑共性与状态机

### 4.1 状态机

```
下单 → 施工 → 运行 ⇄ 停机（断供，语义见 resources.md §6）
         ↓       ⇅ 升级中（按当前等级运行）
        被毁    拆除中（停机）→ 已拆除
```

- 升级中：按当前等级正常工作；完成后血量上限与功能更新。
- 停机：不工作、不掉血、不耗电；覆盖恢复即续。
- 被毁：不退款，释放占用；残骸不占格，可原址重建；占容资产被毁触发感疫转化（waves-enemies.md §8.1）。

### 4.2 维修

- **手动维修（一幕起）**：选中建筑 → 维修开关；持续耗币回血；速率必须远低于波次 DPS（否则墙永动，§9.3）。
- **维修舱（二幕起）**：自动维修自身半径内建筑，耗币；手动维修仍可用（冗余是玩家的选择）。
- 维修不占容量、不占电力。
- **维修不可作用于施工中的建筑**：施工期血量即进度，自然爬升至满。

### 4.3 升级与主脑升级

- 常规升级：付费 + 升级时间；每建筑 1–2 个等级（参数槽，二幕起解锁）。
- **主脑升级（幕切换）**：造价高、时间长、**不可取消**——承诺即风险；期间基地照常运转，主脑可被攻击如常；完成时解锁新幕建筑、威胁基线上升（game-design-concept.md §7）。
- **主脑升级的唯一前置 = 资源门槛**：无波次条件、无建筑数量条件，门槛就是造价本身（下单即全额支付）。攒钱即取舍：为升级攒钱 = 同期防御投入被挤占，这正是早升的真实代价（§9.7）；节奏完全归玩家，与"升级是亲手工程，不是计时器"对齐。
- 主脑升级同步提升其电力容量/覆盖基数（占位接口：二幕起扩张的另一半来源）。

### 4.4 占格与阻挡

- 方格网格；占格参数槽（主脑最大，墙/中继 1×1）。
- 所有建筑阻挡单位通行。
- 友军占位：允许下单，完成时挤开；敌军占位：该格无效。
- 无朝向、无旋转；墙连接自动判定。

## 5. 生产接口（组装厂 / 重装工厂）

- 队列：每厂独立（长度参数槽）；下单时支付造价并**占用容量**（占用在付款时，不在出厂时——与建筑一致）。
- 断供：队列暂停，进度保留。超载：禁止新下单，队内已付项目继续完成。
- 集结点：每厂可设，出厂单位自动前往。
- 兵种属性、兵力编排、操控不在本稿。

## 6. 经营循环与幕内天花板

- **幕内经济天花板 = 覆盖范围 × 电力容量 × 容量提供**（三约束定义见 resources.md §2）——三者都由主脑基数加本幕建筑决定；这就是"空间即电力"的压力来源，也是拖延升级的隐性代价。
- 安静期循环：产币 → 排程（墙 / 节点 / 炮塔 / 储备升级款）→ 建造时间形成先后 → 波次打断。
- 前置投入的暴露期：节点建得越早越多，收入越早滚动；断供或被毁时损失也越大。
- 一幕覆盖固定：扩张是"覆盖内的布局"，不是领土推进；领土推进从二幕中继开始。

## 7. 首切片

- 建筑：主脑、算力节点、采矿站、装甲墙、哨戒炮塔、雷达站、组装厂；不做能源站、中继节点、铸造站、萃取站（稀有系统首切片不出现）、陷阱、维修舱。
- 经济：算力节点被动产出算力币 + 提供算力容量；主脑提供初始电力；**矿石线**：采矿站贴矿石堆采集，塔/厂/雷达吃矿石件。
- 机制子集：全额支付、全额取消退款（各资源）、并行施工、战斗建造、拖拽连放、手动维修、拆除（部分退款）、**贴点采集与储量耗竭**（矿点储量参数槽，采完站停产；简化实现）。
- 机制排除：断供与级联（一幕无中继，覆盖固定）、维修舱、常规升级、主脑升级（留给三幕闭环切片）、稀有资源与萃取站（首切片不出现）。
- 电力简化：仅"主脑固定容量 + 固定覆盖"两个占位数；放置校验保留电力余量与覆盖检查——为二幕接入预留同一套代码路径。
- 验证重点：game-design-concept.md §13 第 1–5 条（建造乐趣、安静期张力、第一波压迫感、精英交接、失败可读性）。
- 第一次精英波用组装厂产出的基础单位应对，逼玩家从"只靠炮塔"转向"调兵"。

## 8. 可读性与 UI 要求（服务"失败可追溯、不被暗算"）

- 资源条：算力币（含产率）、容量 当前/上限、电力 余量/上限、矿石、金属、稀有（见 operations.md §8）。
- 覆盖可视化：放置模式下覆盖边界高亮，覆盖外不可放置的原因直接标注。
- 放置反馈：无效原因按 §3.2 顺序逐条提示（地形/覆盖/重叠/电力/容量/资源——含缺哪种资源）。
- 矿点反馈：采集站选中显示矿点剩余储量；矿点采完有明确标识（站停产 + 储量归零）。
- 停机标识：断供建筑有明确图标；点击可溯源"哪一节中继断了"。
- 在建进度与血量统一为一条：进度 = 血量爬升，一条两个含义。

## 9. 调参目标（代替数值的设计约束）

1. **快墙慢楼**：墙的建造时间 ≤ 玩家看到破口后的反应窗口；大件（组装厂、主脑升级）的建造时间占波间间歇（~8min）的显著比例——一个间歇只排得下少数大件，排程压力来自"待办总量 > 间歇总量"。
2. **节点回本**：回本时间明显小于幕长，且 ≈ 波间和平间歇——一个间歇回本一次（可滚动、不白给；波间隔 10min 下回本 7.5min 的松紧见 values.md 待决）。
3. **维修不上墙**：维修速率 ≪ 常规波次对墙的 DPS——机潮中修墙只能救急，不能永动。
4. **一幕电力天花板**：初始电力允许的节点数 < 一幕中期的理想需求——电力就是一幕的扩张压力来源。
5. **第一波可守有损**：第一波强度落在"满编第一道墙能守，但会掉血、需要维修"的区间（验证点 3）。
6. **拆除退款比 < 1**：重构防线有真实成本，但不惩罚到不敢重构。
7. **主脑升级造价 ≈ 幕内数波的满收入**：早升要牺牲防御投入，晚升要接更强波——两个方向的代价都真实（game-design-concept.md §7）。
8. **精英可被塔杀伤但代价过高**（方案见 waves-enemies.md §8.2）：原型机 HP 与炮塔 DPS 之比应使"纯塔防线"在时间上守不住（血厚 + 电磁庇护下的机潮压力），但塔火仍 contributing——调参方向是"塔能打、打不完，部队集火才收得了尾"。

|---|---|---|---|

| 特有 | 射程、射速、预警半径、陷阱冷却… | 个别建筑 | 各自推演 |

## 11. 非目标

- 无建造单位、无全局施工队列（所选交互的必然推论）。
- 不做建筑朝向与旋转。
- 不做自动布局；第三幕调度中心的自动化仅限"电网扩展政策"（见 §2.4）。
- 资源侧非目标（击杀产币、第二货币等）见 resources.md §9。
