# 资源系统（机器人 / 算力皮）

## 1. 主题与术语

主题：机器人殖民地；敌人是失控的量产机器人（机潮）；货币是区块链式算力币，俗称挖矿。

| 基础设定 | 机器人 / 算力皮 |
|---|---|
| 尸潮 / 波次 | 失控机潮 / 机潮 |
| 物资 / 金 | 算力币 |
| 木 + 石 | 矿石（TAB 木石成本相加合并） |
| 铁 | 金属 |
| 油 | 稀有资源 |
| 采石场 | 采矿站 |
| 铸造厂 | 铸造站（TAB Foundry 同构：直接采集，非加工链） |
| 采油站 | 萃取站 |
| 人口 | 算力容量 |
| 住房 / 木屋 | 算力节点 |
| 指挥中心 / 主核心 | 主脑 |
| 食物（未来） | 冷却液 |
| 精英 | 原型机 / 重装机 |
| 核心被毁 | 主脑被毁 |

## 2. 经济结构

**一个软通货（算力币）+ 三种采集资源（矿石 / 金属 / 稀有资源）+ 一个总量约束（算力容量）+ 一个空间约束（供电网络）**。

- **算力币 = 软通货**：通用货币，节点被动产出，支付一切"运营"性开销（建造、生产、维修、升级）。
- **采集资源 = 料**：不流通、不兑换；建筑与升级按图纸消耗。矿石 = 前期主料（防御与基础件），金属 = 中后期主料（军备与高级件），稀有资源 = 幕末冲刺件（三条线专用）。
- 木不引入：TAB 的木 + 石在本作合并为矿石（成本相加直搬）。

## 3. 算力币（软通货）

- 来源：算力节点被动产出（产币率参数槽，见 building-economy.md §10）。**击杀无收益、残骸无回收**：收入只来自基地自身，不激励离巢追杀——强化建造优先。
- 去向：建筑造价、常规升级、单位生产、维修、主脑升级。
- 支付时机：**下单（放置确认）时全额支付**；退款细则见 building-economy.md §3.3。
- 库存无上限；无存储建筑、无利息。

## 4. 采集资源（矿石 / 金属 / 稀有资源）

- **来源 = 采集地形与矿点**：贴地图资源点（矿石堆 / 金属矿脉 / 稀有点位）建采集站被动产出，无采集单位、无精炼链。
- **每资源一座采集站**：

| 采集站 | 采集对象 | 解锁幕 | 产率 |
|---|---|---|---|
| 采矿站 | 矿石堆（贴地形散布） | 幕一 | +ore 参数槽 |
| 萃取站 | 稀有点位（每图 2–4 处） | 幕一后段 | +rare 参数槽 |
| 铸造站 | 金属矿脉（离散分布） | 幕二 | +met 参数槽 |

- **稀有资源定位**：地图有限矿点（每图 2–4 处）；**只用于三条线**——主脑升级、高级重装工厂、调度中心；首切片不出现。
- **矿点储量有限**（储量参数槽）：采完后矿点消失，采集站停产保留（可拆除部分退款）——扩张由储量消耗驱动，占新点 = 领土推进的动力之一。
- **采集链入口纯币**：采集站自身造价只耗算力币不吃料——避免"建矿站先要料、料又要矿站"的鸡生蛋死锁。
- 支付与退款：与算力币同一规则——下单全额支付（币 + 料一起付）、取消全额退、拆除按退款比各资源同比例退。
- 库存无上限；无存储建筑、无兑换（不做多的设定）。
- 断供：采集站断供停产（同算力节点产币停的语义）。
- 感疫口径：采集站占容、被毁触发感疫；"按造价定比"的多资源折算口径归数值稿。

## 5. 算力容量（总量约束，软）

- 提供：主脑基数 + 算力节点。占用：**全部建筑 + 全部单位**（算力节点与装甲墙除外——节点是净提供者，墙不吃容量：墙是数量最多的建筑，吃容量会饿死军队）。
- 软约束语义：
  - 超载（占用 > 提供）：**禁止下单与生产**；已有建筑、单位、在建工程照常运转。
  - 超载来源：节点被毁、节点断供（见 §6）、单位阵亡释放、拆除释放。
- UI：当前/上限条；超载变红并禁用相关按钮——禁用但不隐藏，玩家必须知道"为什么不能建"。

## 6. 电力（空间约束，硬）——两个子机制，分开实现

- **电力容量（数值）**：主脑基数 + 能源站提供。建筑下单时**预留占用**（预留制，电力容量因此永不超载）。
- **供电覆盖（空间）**：主脑基数 + 中继节点延伸。**所有建筑必须建在覆盖内**（含装甲墙：在覆盖内，但耗电为零——覆盖是"领土"，耗电是"运行成本"）。
- 释放时机：被毁、拆除完成。
- **断供 = 覆盖消失**（预留制下容量不可能超限）。语义表：

| 建筑 | 覆盖消失时 |
|---|---|
| 算力节点 | 产币停；**容量提供归零** → 触发 §5 超载，但不叠加停机 |
| 采矿站 / 铸造站 / 萃取站 | 采集停 |
| 哨戒炮塔 / 电磁陷阱 / 雷达站 / 维修舱 | 功能停 |
| 组装厂 / 重装工厂 | 队列暂停，进度保留 |
| 中继节点 | 自身失效 → 下游级联失效 |
| 装甲墙 | 不受影响（零耗电） |
| 主脑 | 不可断供（自供能） |

- 恢复：覆盖恢复（修复/重建中继）后全部自动恢复，无累积损失。
- **施工与升级不受断供影响**（物理工程不依赖电网）；完成时若覆盖未恢复，直接进入停机态。

## 7. 惩罚的边界（守 game-design-concept.md §9 底线）

- 电网问题 → 停机（不产不出，但完好无损）。
- 容量问题 → 禁新建（不冻结现有）。
- 料不足 → 禁新建（同容量类：任一资源不足即无法下单，已有物不受影响）。
- 不叠加：断供引发的超载不导致任何已有物停止工作。

## 8. 冷却液（未来）

食物的换皮，作为容量使用，不是第二钱包；不改变本结构。冷却液是否吃料、占不占采集位，待定。

## 9. 非目标（资源侧）

- 不做击杀产币、残骸回收——战斗收益为零。
- 不做资源兑换 / 市场，不做采集资源间转换。
- 不做矿石 → 金属精炼链（两者是独立采集的矿种，非上下游）。
- 不做存储建筑、库存上限、利息。
